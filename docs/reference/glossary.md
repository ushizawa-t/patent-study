# 用語集

<p class="lead">審査基準によく出てくる言葉をまとめました。「定義」は審査基準の言葉をもとにしています。</p>

| 用語 | 意味 | 教材 |
|---|---|---|
| 一応の合理的な疑い | 機能・特性などの記載のせいで厳密に対比できないとき、新規性・進歩性が否定されると一応合理的に疑えること。この場合に限り、理由を説明して拒絶理由が通知される | [B11](/core/b11-special-claims) |
| 引用発明 | 新規性・進歩性の判断のために引用する先行技術 | [B4](/core/b4-cited) |
| 引用発明特定事項 | 引用発明を文言で表現する場合に必要と認められる事項 | [B5](/core/b5-compare) |
| 上位概念 | 同族的・同類的事項を集めて総括した概念、またはある共通する性質に基づいて複数の事項を総括した概念（例：「弾性体」に対する「バネ」は下位概念） | [B4](/core/b4-cited) |
| 拡大先願 | 29条の2。本願出願後に公開された先の出願の当初明細書等に記載された発明と同一の発明を拒絶する規定 | [C1](/related/c1-enlarged-prior) |
| 慣用技術 | 周知技術であって、かつ、よく用いられている技術 | [B7](/core/b7-inventive-basic) |
| 技術常識 | 当業者に一般的に知られている技術（周知技術及び慣用技術を含む）又は経験則から明らかな事項 | [B7](/core/b7-inventive-basic) |
| 技術水準 | 先行技術のほか、技術常識その他の技術的知識（技術的知見等）から構成されるもの | [B7](/core/b7-inventive-basic) |
| 公知 | この教材（審査基準第III部）では、29条1項1号〜3号のいずれかに該当すること | [B2](/core/b2-prior-art) |
| サブコンビネーション | 二以上の装置・工程を組み合わせた全体（コンビネーション）に対し、組み合わされる各装置・各工程 | [B11](/core/b11-special-claims) |
| 事実上の選択肢 | 包括的な表現によって、実質的に有限の数の、より具体的な事項を包含するように意図された記載（例：「C1〜C10のアルキル基」） | [B5](/core/b5-compare) |
| 実質同一 | 相違点が、課題解決のための具体化手段における微差（周知技術・慣用技術の付加、削除、転換等で、新たな効果を奏さないもの）である場合など | [C1](/related/c1-enlarged-prior) |
| 周知技術 | その技術分野において一般的に知られている技術（相当多数の文献がある、業界に知れ渡っている、例示の必要がないほどよく知られている、など） | [B7](/core/b7-inventive-basic) |
| 主引用発明 | 進歩性の判断で出発点にする、論理付けに最も適した一の引用発明 | [B8](/core/b8-inventive-negative) |
| 選択発明 | 物の構造に基づく効果の予測が困難な技術分野で、上位概念・選択肢で表現された公知の発明から選択された下位概念の発明で、新規性が否定されないもの | [B11](/core/b11-special-claims) |
| 阻害要因 | 副引用発明を主引用発明に適用することを阻害する事情 | [B9](/core/b9-inventive-positive) |
| 当業者 | その発明の属する技術の分野における通常の知識を有する者（技術常識を持ち、通常の技術的手段を使え、通常の創作能力を発揮でき、技術水準を全て知識にできる者） | [B7](/core/b7-inventive-basic) |
| 動機付け | 主引用発明に副引用発明を適用しようとする理由。技術分野の関連性、課題の共通性、作用・機能の共通性、引用発明の内容中の示唆を総合考慮する | [B8](/core/b8-inventive-negative) |
| 特別な技術的特徴 | 発明の先行技術に対する貢献を明示する技術的特徴（単一性の判断で使う） | [C7](/related/c7-unity) |
| 除くクレーム | 請求項の記載表現を残したまま、一部の事項のみを除外することを明示した請求項 | [C8](/related/c8-amendment) |
| 発明特定事項 | 請求項に係る発明を特定するための事項 | [B1](/core/b1-claim) |
| 副引用発明 | 主引用発明に適用する他の引用発明 | [B8](/core/b8-inventive-negative) |
| 分説 | 請求項を構成要素ごとに分けて書くこと（実務上の用語） | [B5](/core/b5-compare) |
| 本願 | 審査（判定）の対象になっている特許出願 | [B1](/core/b1-claim) |
| 用途発明 | ある物の未知の属性を発見し、その属性により、その物が新たな用途への使用に適することを見いだしたことに基づく発明 | [B11](/core/b11-special-claims) |
| 論理付け | 先行技術に基づいて、当業者が請求項に係る発明を容易に想到できたことの論理の構築 | [B7](/core/b7-inventive-basic) |
| 後知恵 | 本願の発明を知ったうえで、容易に想到できたように見えたり、引用発明を本願に引きずられて認定したりすること | [B10](/core/b10-inventive-notes) |
