# 要件の比較表

<p class="lead">新規性・進歩性・拡大先願・先願・新規性喪失の例外。似ているけれど少しずつ違う要件を、一覧で比べます。</p>

## 29条・29条の2・39条

| | 新規性（29条1項） | 進歩性（29条2項） | 拡大先願（29条の2） | 先願（39条） |
|---|---|---|---|---|
| 比べる相手 | 出願**前**に公知になった発明 | 出願**前**に公知になった発明 | 本願の出願**日前**に出願され、本願出願**後**に公開された他の出願 | 先願・同日出願 |
| 相手の範囲 | 刊行物・ウェブ・公知・公然実施 | 同左 | 他の出願の**当初明細書等の全体** | 他の出願の**請求項** |
| どこまでダメ？ | 同一（相違点なし） | 当業者が**容易に**発明できた | 同一（**実質同一**を含む） | 同一（**実質同一**を含む） |
| 発明者・出願人が同じなら？ | 関係なし | 関係なし | 発明者同一、または本願出願時に出願人同一なら**適用なし** | **出願人が同じでも適用** |
| 判断の基準 | 出願の**時**（時刻まで） | 出願の**時** | 出願の**日** | 出願の**日** |
| 相手の内容は補正で変わる？ | 変わらない | 変わらない | 変わらない（補正で削除されても影響なし） | 変わりうる（請求項は補正される） |
| 教材 | [B6](/core/b6-novelty) | [B7〜B11](/core/b7-inventive-basic) | [C1](/related/c1-enlarged-prior) | [C2](/related/c2-prior-app) |

::: tip 実質同一とは
- 29条の2・39条共通：課題解決のための具体化手段における**微差**（周知技術・慣用技術の付加、削除、転換等で、新たな効果を奏さないもの）
- 39条（先願）ではさらに：先願発明を本願で**上位概念**として表現した差異、単なる**カテゴリー表現上**の差異
:::

## 新規性喪失の例外（30条）

| | 1項 | 2項 |
|---|---|---|
| 対象 | 権利者の**意に反して**公開された発明 | 権利者の**行為に起因して**公開された発明（特許公報等への掲載によるものを除く） |
| 期間 | 公開から1年以内に出願 | 公開から1年以内に出願 |
| 手続 | 意見書・上申書等で合理的に説明 | 出願と同時にその旨の書面＋出願から30日以内に証明書 |
| 教材 | [C3](/related/c3-grace-period) | [C3](/related/c3-grace-period) |

## 判断の基準時

| 出願の種類 | 新規性・進歩性の基準時 |
|---|---|
| 通常の出願 | 特許出願の時 |
| 分割出願・変更出願・実用新案登録に基づく特許出願 | 原出願の出願時 |
| 国内優先権の主張を伴う出願 | 先の出願の出願時（先の出願の当初明細書等に記載された発明について） |
| パリ条約による優先権の主張を伴う出願 | 第一国出願の出願日 |
| 国際特許出願 | 国際出願日（優先権の主張を伴う場合は上欄のとおり） |
