# 対比表ワーク

<p class="lead">請求項を発明特定事項に分け、引用発明と一つずつ比べていく練習です。「一致」か「相違」かを選んで、答え合わせをしてみましょう。</p>

::: tip ポイント
- 言葉が違っても**意味が同じ**なら一致、言葉が似ていても**中身が違えば**相違
- 引用発明に<strong>書いていない（不明な）</strong>事項は、相違点として扱う
- 引用発明に**余分な構成**があっても、それ自体は相違点にならない（[B6](/core/b6-novelty)）
:::
