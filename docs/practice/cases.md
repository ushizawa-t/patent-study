# 事例演習（附属書A）

<p class="lead">特許庁の「事例集」（審査ハンドブック附属書A）から、製造業でイメージしやすい事例を選びました。まず自分で結論と理由を考えてから、「答えと解説」を開いてください。</p>

::: warning 事例集を使うときの注意
事例集の請求項などは、説明しやすいように簡略化されています。また、引用文献や技術常識は**説明のための前提として設定されたもの**で、実際の技術水準を反映したものではありません（附属書A 進歩性事例集の留意事項）。
:::

## 事例A：レンズ（新規性）

<div class="example">

本願（請求項1）

5μm〜6μmの厚さに形成された物質A層と、1μm〜2μmの厚さに均一に形成された物質B中間層と、ガラス基板とを備えるレンズ。

本願の明細書の抜粋（要約）

反射を抑えるため物質A層とガラス基板の間に物質B中間層を設けることは従来から提案されていたが、中間層の厚さが5μm以下になると厚さを測定できず、薄い中間層を均一に形成することは困難だった。本発明者らは、C干渉計を使えば薄くても測定できることを見いだし、1μm〜2μmに均一に形成すると最も反射が抑えられることがわかった。

引用文献の抜粋（要約）

物質A層で5μmコーティングされた無反射レンズが知られているが、波長の長い反射光を完全には抑えられない。そこで、厚さ7μm以下の物質B中間層を均一に設けて、広い波長範囲で反射を抑えることに成功した。なお、最適な中間層の厚さは測定によって見いだせばよいが、例えば1μm程度でもよい。

</div>

**考えてみよう**：引用文献には「1μm程度でもよい」と書いてあります。本願の請求項1は新規性を有するでしょうか？

::: details 答えと解説
**結論：新規性あり**

引用文献には、中間層を7μm以下に均一に設けること、一例として1μm程度でもよいことは書いてあります。しかし、

- 中間層を**どうやって**1μmに均一に設けるのかは書いていない
- 「5μm以下の中間層の厚さは測定できない」という出願時の技術常識からすると、1μm〜2μmに厚さを制御して設けることは困難

なので、当業者が引用文献と技術常識から請求項のレンズを**作れる**とはいえません。よって、引用文献のうち中間層5μm以下のものは「引用発明」にできず、新規性ありとなります。

→ 学ぶポイント：[B4 作れない・使えないものは引用できない](/core/b4-cited)

:::

## 事例B：プリンタ（進歩性）

<div class="example">

本願（請求項1）

プリンタ本体の動作状態を通常動作状態または省電力動作状態のいずれかに設定する制御部を備え、制御部は、通常動作要求または省電力動作要求が**所定時間連続して維持された**ことが確認できた場合にのみ、その要求が有効であると判断するプリンタ。

課題：要求信号のエッジで判断すると、ノイズが乗ったときに誤検出する。

技術水準

- 引用発明1：通常動作／省電力動作に設定する制御部を備えたプリンタ（信号のやりとりは書いてあるが、**ノイズによる誤動作については書いていない**）
- 周知技術：ノイズ混入による誤動作防止のため、信号が所定期間継続したとき初めて有効とする（文献はプリンタ分野に限らず、電気信号をやりとりするもの一般に適用できると読み取れる）

</div>

**考えてみよう**：引用発明1にはノイズの課題が書かれていません。それでも動機付けはあるでしょうか？

::: details 答えと解説
**結論：進歩性なし**

- 相違点：要求が所定時間連続して維持された場合にのみ有効と判断する点
- **課題の共通性**：引用発明1にはノイズの課題は書いていないが、電気信号のやりとりである以上ノイズが混じって誤動作する可能性があることは当業者に**自明**。つまり引用発明1にもその課題が**内在**している
- よって、周知技術を適用して相違点の構成とすることは容易

→ 学ぶポイント：[B8 課題の共通性（自明な課題）](/core/b8-inventive-negative)

:::

## 事例C：電流センサ（進歩性）

<div class="example">

本願（請求項1・要約）

電源と負荷の間に接続された1次コイル機能の電流要素と、それと磁気的に結合する2次コイルと、出力端子とを備えた電流センサで、**電流要素と2次コイルが多層基板上に形成される**もの。課題は、小型で高精度のAC電流検出器を提供すること。

技術水準

- 引用発明：導電体（1次巻き線）を、スリーブを介して**1対の環状コイル**で囲み、両コイルの出力を加算して**外部磁場の影響を打ち消す**電流センサ。コイル巻きのばらつきで対称性が崩れるため、補償ターンで調整する
- 周知技術：変圧回路の1次コイル・2次コイルを、絶縁基板を積層した**多層基板上**に形成する（課題は、基板上でもコイル間の磁気結合を十分にすること）

</div>

**考えてみよう**：技術分野（変圧回路）は関連しています。進歩性はあるでしょうか？

::: details 答えと解説
**結論：進歩性あり**

- 技術分野の関連性：どちらも変圧回路に関するもので関連はある
- **課題の共通性**：引用発明の課題は「外部磁場に対する補償（1対の環状コイルの対称性）」、周知技術の課題は「基板上でも磁気結合を十分にする」で、**相違**
- 示唆：引用発明に、2次コイルを環状コイル以外にする可能性の示唆はない
- → **動機付けがあるとはいえない**
- さらに、環状コイルを多層基板上のコイルに置き換えると、外部磁場の補償という前提が**機能しなくなる** → **阻害要因**もある

→ 学ぶポイント：技術分野が関連していても、それだけでは動機付けにならない（[B8](/core/b8-inventive-negative)）／阻害要因（[B9](/core/b9-inventive-positive)）

:::

## 事例D：洗濯機の脱水槽（進歩性）

<div class="example">

本願（請求項1・要約）

かしめ接合した金属板の円筒状胴部、底板、バランスリング、プラスチック製カバーとフィルタを持つフィルタ部材を備えた洗濯機の脱水槽で、フィルタ部材が胴部の接合部を内側から覆い、さらに

- フィルタ部材の上端部に、脱水槽内に延びる**延設部材**がある
- フィルタ部材の上端部とバランスリングとの間に**隙間を残して**いる

課題：樹脂部材と金属胴部の熱収縮量の違いで冬場に隙間ができ、洗濯物が挟まって傷つく。

技術水準

- 引用発明1：ステンレス胴部の継ぎ目を、底板からバランスリングまで**隙間なく**樹脂製循環路体で覆った脱水槽（水を底部から上昇循環させて散水する。節水・洗剤溶解、継ぎ目への引っかかり防止・見栄えが目的）。循環路体は内壁面に**固着**
- 引用発明2：**樹脂製**胴部の側壁に**着脱自在**のフィルタ部材を設け、カバー上端に延設部材、フィルタ部材上端とバランスリングの間に**指が入る程度の隙間**を設けた脱水槽（フィルタのショートカット防止、異なる樹脂の熱膨張差でフィルタが外れなくなる問題の解決、着脱を容易にするのが目的）

</div>

**考えてみよう**：引用発明2には「延設部材」も「隙間」も書いてあります。引用発明1に引用発明2を適用して、請求項1の発明に到達できるでしょうか？

::: details 答えと解説
**結論：進歩性あり**

- 相違点：フィルタ部材の延設部材と、バランスリングとの間の隙間
- (1) 技術分野：どちらも「脱水槽にフィルタ部材を備えた洗濯機」で**同じ**
- (2) 課題：引用発明1（節水・継ぎ目の引っかかり・見栄え）と引用発明2（ショートカット防止・着脱性）で**共通しない**。しかも引用発明2は樹脂一体成形で継ぎ目がないので、継ぎ目の課題を想定できない
- (3) 作用・機能：どちらも「フィルタ機構」とはいえるが、引用発明1は底部から上昇循環させて散水、引用発明2は側縁から入れて前面から出す流れで、水の流れが異なり**共通しない**。また、引用発明1は固着・異材質、引用発明2は同種の樹脂が前提で、置き換える理由がない
- (4) 示唆：どちらの文献にも**示唆はない**
- → 総合考慮して**動機付けがあるとはいえない**

→ 学ぶポイント：相違点の構成が副引用発明に「書いてある」だけでは足りず、主引用発明に**適用する動機付け**が必要（[B8](/core/b8-inventive-negative)）

:::

## 事例E：周期的分極反転領域を持つ基板の製造方法（進歩性）

<div class="example">

本願（請求項1・要約）

Li2O/(Ta2O5+Li2O)のモル分率が0.495以上0.505未満の、**MgOをドープ**したタンタル酸リチウム単結晶基板に周期電極とベタ電極を設け、**直流電界**を印加して周期的分極反転領域を形成する製造方法。

技術水準

- 引用発明：**Li過剰**の定比組成に近いタンタル酸リチウム単結晶に電界を印加して周期的分極反転領域を作る方法。文献には「従来のTa過剰組成では耐光損傷のため**MgO**などを添加していたが、**MgOを添加すると分極反転の制御性がMgO濃度に依存して再現性よく作るのが難しい**」という問題点が書かれ、引用発明はその解決（MgOなしで耐光損傷閾値が高く制御性のよい素子）を課題としている
- 周知技術：MgOを添加して光透過率を上げる・分極反転電圧を下げること／直流電界を用いること

</div>

**考えてみよう**：動機付けはありそうです。それでも進歩性が認められる理由は何でしょうか？

::: details 答えと解説
**結論：進歩性あり**

- 動機付け：同じ技術分野で、光透過率の向上や印加電圧の低減は光素子の分野で**自明な課題**なので共通 → 動機付けは**ある**
- **阻害要因**：引用発明は「MgOの添加によって発生する問題点の解決」を課題としているので、MgOを添加する周知技術を適用することは**引用発明の目的に反する**
- その阻害要因は、動機付けを考慮しても**なお適用を妨げる程度**のもの → 容易に想到し得たとはいえない

→ 学ぶポイント：動機付けがあっても、阻害要因の**程度**しだいで進歩性は肯定される（[B9](/core/b9-inventive-positive)）

:::
