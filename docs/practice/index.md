# 演習のすすめ方

<p class="lead">読んで「わかった」と、自分で「できる」は別物です。ここでは手を動かして、判定の流れを体に覚えさせましょう。</p>

| 演習 | やること | 目安時間 |
|---|---|---|
| [判断フローを体験する](/practice/flow) | 新規性 → 進歩性の判断手順を、質問に答えながらたどる | 5分 |
| [対比表ワーク](/practice/compare) | 請求項の各要素が引用発明と一致か相違かを判断する | 1問10分 |
| [事例演習（附属書A）](/practice/cases) | 特許庁の事例集を使って、結論と理由を考える | 1問20〜30分 |

::: tip おすすめの使い方
- まず **B1〜B10 を読んでから**取り組むと効果的です
- 事例演習は、答えを見る前に**自分の結論と理由をメモ**してから開きましょう
- 新人同士で「自分はこう考えた」を話し合うと、もっと身につきます
:::

::: warning 社内判定の最終演習
慣れてきたら、実際の発明提案書（過去の案件）を使って、

1. 発明を分説して請求項案をつくる
2. 先行技術調査をする
3. 対比表をつくる
4. 新規性・進歩性の判定メモを書く（主引用発明・相違点・論理付け・肯定的事情）
5. 研究員さんへの説明と、明細書に書いてほしいことをまとめる

までを一通りやってみましょう。教育担当者がレビューします。
:::
