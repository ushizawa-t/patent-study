# この教材の使い方

<p class="lead">ようこそ、知財部へ。この教材では、研究員さんが考えたアイデアについて「新規性・進歩性がありそうか」を判定するための考え方を、特許庁の審査基準に沿って学びます。</p>

## どんな順番で進めればいい？

おすすめの順番はこちらです。

1. **A. はじめに**（このパート）で、判定業務の全体像をつかむ
2. **B. 新規性・進歩性**を B1 から順番に読む（ここが本丸です）
3. **C. 周辺の要件**のうち、C1〜C4 は必ず読む。C5 以降は必要になったときでOK
4. **D. 演習**で、実際に手を動かしてみる

各ページの最後には確認クイズがあります。読み終わったら「このページを学習済みにする」ボタンを押しておくと、下の一覧に ✓ が付きます。

::: tip 記録について
学習済みの記録やクイズの点数は、**いま使っているブラウザの中にだけ**保存されます。ほかの人に見られることはありませんが、別のパソコンやブラウザでは引き継がれません。
:::

## ページの読み方

各ページでは、次のような囲みを使い分けています。

::: tip ざっくり言うと
まず全体のイメージをつかむための、やさしい要約です。
:::

::: info 原文（審査基準・条文など）
条文や審査基準の文章は、**言い換えずにそのまま**載せています。ニュアンスが大事なので、慣れてきたら原文を読む練習もしてみてください。
:::

::: warning 社内判定では
審査官ではなく「出願前に社内で判定する立場」だと、どこに気をつければいいかをまとめています。
:::

::: danger よくある間違い
新人のうちにつまずきやすいポイントです。
:::
