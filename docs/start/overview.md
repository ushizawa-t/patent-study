# A1 判定業務の全体像

<p class="lead">まずは「特許庁の審査はどう進むのか」と「私たちの社内判定はそのどこに当たるのか」を、地図のように頭に入れておきましょう。</p>

## 特許庁の審査の流れ

審査官は、だいたい次の順番で出願を審査します（審査基準 第I部第1章・第2章）。

```
本願発明の認定
   ↓
調査対象の決定 → 先行技術調査
   ↓
拒絶理由を見つけた？
   ├─ No  → 特許査定
   └─ Yes → 拒絶理由通知（最初）
              ↓
         意見書・補正書の提出（出願人）
              ↓
         拒絶理由は解消した？
           ├─ Yes → 特許査定（他の拒絶理由がなければ）
           └─ No  → 拒絶査定 / 最後の拒絶理由通知 …
```

::: info 原文（基準 I-1 2.1(1)）
審査官は、まず審査の対象となっている特許出願(以下この部において「本願」という。)の明細書、特許請求の範囲及び図面を精読し、発明の技術内容を十分に理解する。
:::

::: info 原文（基準 I-1 2.1(3)）
審査官は、発明の単一性の要件、記載要件、新規性、進歩性等の検討及びそのほかの拒絶理由の有無の検討をした結果、拒絶理由を発見しなかった場合は、特許査定をする(第51条)。<br>
審査官は、拒絶理由を発見した場合は、拒絶理由通知をする(第50条)。拒絶理由通知には、「最初の拒絶理由通知」及び「最後の拒絶理由通知」の二種類があるが、一回目の拒絶理由通知は必ず「最初の拒絶理由通知」である。
:::

::: details 「最初の拒絶理由通知」と「最後の拒絶理由通知」って？
1回目の拒絶理由通知は「最初」、そのあと補正によって新たに必要になった拒絶理由だけを通知するときは「最後」になります。「最後」のあとは補正できる範囲がぐっと狭くなります。詳しくは [C9 拒絶理由通知の読み方](/related/c9-office-action) で扱います。
:::

## 社内判定は、どこに当たる？

社内判定は、出願**前**に、審査官がやることを**先回りしてシミュレーションする**作業だと考えるとわかりやすいです。

| 特許庁の審査 | 社内判定（出願前） |
|---|---|
| 請求項を読んで発明を認定する | **研究員のアイデアを、請求項っぽく分解する**（ここが一番の違い！） |
| 先行技術調査 | 社内でも先行技術調査（特許文献・論文・製品情報など） |
| 引用発明を認定し、対比する | 同じ |
| 新規性・進歩性を判断する | 同じ。さらに「どうすれば通りそうか」まで考える |
| 拒絶理由通知 → 意見書・補正 | 判定結果を研究員に説明し、明細書に書くべきこと（効果のデータなど）を伝える |

::: warning 社内判定では
審査はもう書かれた請求項からスタートしますが、社内判定では**まだ請求項がありません**。研究員さんの説明（発明提案書・実験データ・図）から、

- 何が発明の本質なのか（課題と、それを解決する手段）
- どこまで広く書けそうか（上位概念）、どこまで絞れば確実か（下位概念）

を整理して、**発明特定事項に分けて**から先行技術と比べます。B1 と B5 で練習します。
:::
