# A2 審査基準とハンドブック

<p class="lead">この教材のもとになっている資料と、その読み方です。困ったときに原文にあたれるようになると、ぐっと強くなれます。</p>

## 3つの資料の関係

| 資料 | どんなもの？ | 例えるなら |
|---|---|---|
| **特許法などの法令** | ルールそのもの | 法律 |
| **特許・実用新案審査基準** | 法律を審査でどう当てはめるかの「基本的な考え方」 | 公式の解説書 |
| **特許・実用新案審査ハンドブック** | 審査の手続や注意点、そして**事例集・裁判例**（附属書） | 実務マニュアル＋問題集 |

::: info 原文（審査基準「改訂に当たって」より）
特許・実用新案審査基準は、特許法等、関連する法律を審査官が出願の審査において適用するための一般的な指針としてのみならず、出願人が特許庁における審査実務の理解を深めるためにも広く利用されています。
:::

::: info 原文（審査ハンドブック「改訂に当たって」より）
審査ハンドブックは、手続的事項や留意事項に加えて、附属書として、審査基準で示された基本的な考え方を理解する上で有用な事例、裁判例、特定技術分野への適用例を掲載することとしました。
:::

## 審査基準の構成

全部で10部あります。この教材で特に大事なのは **第III部 特許要件** です。

| 部 | 内容 | 教材での扱い |
|---|---|---|
| 第I部 | 審査総論（審査の流れ・先行技術調査など） | A1、C4、C9 |
| 第II部 | 明細書及び特許請求の範囲（記載要件・単一性） | C6、C7 |
| **第III部** | <strong>特許要件（発明該当性・新規性・進歩性・拡大先願・先願など）</strong> | **B 全体、C1〜C3、C5** |
| 第IV部 | 補正 | C8 |
| 第V部 | 優先権 | C10 |
| 第VI部 | 特殊な出願（分割など） | C10 |
| 第VII〜X部 | 外国語書面出願、国際特許出願、存続期間の延長、実用新案 | C11 |

## ハンドブックの附属書

| 附属書 | 内容 | 教材での使い方 |
|---|---|---|
| 附属書A | 「特許・実用新案審査基準」事例集（新規性・進歩性の事例が多数） | D. 演習 |
| 附属書B | 特定技術分野への適用例（コンピュータソフトウエア・生物・医薬） | 必要に応じて参照 |
| 附属書C | 実用新案技術評価書作成のためのハンドブック | 参考 |
| 附属書D | 審判決例集 | 参考 |
