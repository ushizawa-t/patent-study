# C5 発明該当性・産業上の利用可能性

<p class="lead">新規性・進歩性の前に、そもそも「特許法でいう発明」に当たるか、「産業上利用できる」か、という入口の要件があります。</p>

::: tip ざっくり言うと
- 特許法の「発明」＝**自然法則を利用した技術的思想の創作**のうち高度のもの
- 自然法則そのもの、単なる発見、永久機関、経済法則・ゲームのルール・数学の公式・人間の精神活動だけを使うもの（ビジネス方法それ自体など）は「発明」ではない
- 人間を手術・治療・診断する方法は「産業上利用することができる発明」に当たらない
:::

::: info 原文（基準 III-1 1.）
特許法における「発明」は、第2条第1項において、「自然法則を利用した技術的思想の創作のうち高度のもの」と定義されている。この定義にいう「発明」に該当しないものに対しては特許が付与されない。また、この定義にいう「発明」に該当するものであっても、特許法の目的が産業の発達にあることから(第1条)、特許を受けようとする発明は、産業上利用することができる発明でなければならない。
:::

## 「発明」に当たらない6つの類型

::: info 原文（基準 III-1 2.1）
(i) 自然法則自体(2.1.1参照)<br>
(ii) 単なる発見であって創作でないもの(2.1.2参照)<br>
(iii) 自然法則に反するもの(2.1.3参照)<br>
(iv) 自然法則を利用していないもの(2.1.4参照)<br>
(v) 技術的思想でないもの(2.1.5参照)<br>
(vi) 発明の課題を解決するための手段は示されているものの、その手段によっては、課題を解決することが明らかに不可能なもの(2.1.6参照)
:::

| 類型 | 例 |
|---|---|
| 自然法則自体 | エネルギー保存の法則、万有引力の法則 |
| 単なる発見 | 天然の鉱石の発見（ただし天然物から**人為的に単離した**化学物質・微生物は発明） |
| 自然法則に反する | いわゆる永久機関 |
| 自然法則を利用していない | 経済法則、ゲームのルールそれ自体、数学上の公式、人間の精神活動、ビジネスを行う方法それ自体 |

::: info 原文（基準 III-1 2.1.4）
発明特定事項に自然法則を利用している部分があっても、請求項に係る発明が全体として自然法則を利用していないと判断される場合は、その請求項に係る発明は、自然法則を利用していないものとなる(例3から例6まで参照)。<br>
逆に、発明特定事項に自然法則を利用していない部分があっても、請求項に係る発明が全体として自然法則を利用していると判断される場合は、その請求項に係る発明は、自然法則を利用したものとなる。
:::

## ソフトウェア・AI 関連の発明

コンピュータソフトウエアを利用するものでも、**機器等の制御**（炊飯器、洗濯機、エンジンなど）や、**対象の技術的性質に基づく情報処理**（エンジン回転数、圧延温度など）を具体的に行うものは、それだけで「発明」に当たります（基準 III-1 2.2(1)）。そうでない場合は、附属書B の考え方で判断します。

::: info 原文（附属書B 第1章 2.1.1.2(1)(i)）
「ソフトウエアによる情報処理がハードウエア資源を用いて具体的に実現されている」とは、ソフトウエアとハードウエア資源とが協働することによって、使用目的に応じた特有の情報処理装置又はその動作方法が構築されることをいう。
:::

IoT・AI 関連の進歩性の事例は 附属書A 進歩性 事例26〜40 にまとまっています。

## 産業上の利用可能性

満たさない類型は次の3つです（基準 III-1 3.1）。

1. 人間を手術、治療又は診断する方法の発明
2. 業として利用できない発明（個人的にのみ利用される発明（例：喫煙方法）、学術的・実験的にのみ利用される発明）
3. 実際上、明らかに実施できない発明

::: warning 社内判定では
製造業の判定では、生産管理・品質管理・保守サービスなど**ビジネス寄りのアイデア**が出てくることがあります。「ビジネスのやり方」だけで終わらず、**センサ・装置・データ処理など技術的な手段**として表現できるかを研究員さんと一緒に考えましょう。附属書A の IoT 関連事例（建設機械保守サーバ、製造ラインの品質管理プログラムなど）が参考になります。
:::
