# C4 先行技術調査の方法

<p class="lead">判定の質は、調査の質で決まります。審査官がどうやって調査範囲を決め、どこで調査を終えるのか。社内での調査にもそのまま使える考え方です。</p>

::: tip ざっくり言うと
- 調査対象は請求項の発明だけでなく、**実施例**や、**補正で請求項に入りそうな事項**も考える
- 発明の詳細な説明に書かれた先行技術文献、外国特許庁の調査結果なども**先に確認**
- **関連性が一番高い分野から**始めて、だんだん広げる
- 十分な文献が見つかった、またはこれ以上探しても見つかりそうにない、となったら終了
- 公知日と出願日（優先日）の関係は**必ず**確認
:::

## 調査の流れ

::: info 原文（基準 I-2-2 1.）
審査官は、先行技術調査をする際は、まず本願の請求項に係る発明から、先行技術調査の対象(以下この部において「調査対象」という。)となる発明を決定する。<br>
そして、本願の発明の詳細な説明に、関連する先行技術文献に関する情報が開示されている場合や、外国特許庁の調査結果若しくは審査結果、登録調査機関の調査結果又は情報提供により提供された情報が確認できる場合は、審査官は、これらの内容を検討した上で、先行技術調査をする。
:::

```
調査対象を決める → 先行技術調査をする → 新規性・進歩性等を判断する
```

## 1. 調査対象を決める

::: info 原文（基準 I-2-2 2.2）
(1) 審査官は、請求項に係る発明の実施例も、調査対象として考慮に入れる。<br>
(2) 審査官は、査定までの審査の効率性を踏まえて、補正により請求項に繰り入れられることが合理的に予測できる事項も調査対象として考慮に入れる。
:::

明らかに新規事項を追加している発明、明らかに「発明」に該当しないもの、明細書を見ても把握できないほど不明確な請求項などは、調査対象から**除外されうる**ことになっています（2.3）。ただし、誤記や軽微な不備があっても明細書等から発明を把握できるなら、その把握した発明で調査します（2.3.1）。

## 2. 調査の手法

::: info 原文（基準 I-2-2 3.1.2(2)）
審査官は、請求項に係る発明に関連する先行技術文献等が発見される蓋然性が最も高い技術分野を優先して先行技術調査をする。通常は、発明の詳細な説明に記載された実施例に最も密接に関連する技術分野から先行技術調査を開始して、漸次、関連性のより低い技術分野へと先行技術調査を拡大することが適切である。
:::

対象は、**国内外の特許文献（国際公開を含む）と国内外の非特許文献**です（3.1.2(1)）。関連性の高い分野で十分な文献が見つからず、関連性の低い分野で見つかる見込みが高いときに、調査範囲を広げます（3.1.2(3)）。

## 3. いつ調査を終える？

::: info 原文（基準 I-2-2 3.1.3）
審査官は、特許請求の範囲に記載された発明について、補正により請求項に繰り入れられることが合理的に予測される事項も考慮しながら先行技術調査をして、関連性の高い先行技術文献等が十分に得られた場合又は調査範囲において、より有意義な関連先行技術文献等を発見する蓋然性が極めて低くなったと判断した場合は、先行技術調査を終了することができる(注)。<br>
なお、請求項に係る発明及びその発明の実施例について、単独で新規性又は進歩性を否定する先行技術文献等を発見した場合は、審査官は、その請求項に関する限り、先行技術調査を終了することができる。<br>
ただし、過度の負担なく他の実施例についても先行技術調査をすることができる場合は、審査官は、更に先行技術調査を続行することが望ましい。
:::

## 4. 判断の前に日付を確認

::: info 原文（基準 I-2-2 4.）
先行技術文献等の公知日は、拒絶理由を構成する上で極めて重要である。したがって、審査官は、新規性、進歩性に関する検討をする際は、それぞれの先行技術文献等の公知日と、本願の出願日(又は優先日)との関係を必ず確認する。<br>
また、審査官は、拡大先願(第29条の2)の適用を検討する場合は、本願の出願日と先願の出願日及び公開日の関係並びに本願と先願の発明者及び出願人が同一でないか否かを必ず確認する。審査官は、先願(第39条) の適用を検討する場合は、本願と先願の出願日の関係を必ず確認する。
:::

調査結果を記録するときは、調査した技術分野を、**国際特許分類（IPC）など**で記載します（3.2）。

::: warning 社内判定では
社内調査のチェックリストです。

- [ ] 研究員さんが知っている**関連文献・競合製品**を最初に聞いた
- [ ] 実施例（具体的な形）と、<strong>広げた形（上位概念）</strong>の両方で調査した
- [ ] 特許文献だけでなく、**論文・学会予稿・製品カタログ・ウェブ**も見た
- [ ] **自社の未公開出願**も確認した（29条の2・39条対策 → [C1](/related/c1-enlarged-prior)）
- [ ] 使った**分類（IPC/FI/Fターム）とキーワード**を記録した
- [ ] 見つけた文献の**公知日**と、出願予定日の関係を確認した
- [ ] 外部の検索サービスに**発明そのものの組合せ語**を入れすぎていない（情報漏えい対策 → [B3](/core/b3-web)）

「調査した範囲」を記録しておくと、あとで「どこまで見たうえでの判断か」が説明できます。
:::
