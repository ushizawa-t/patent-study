# C7 発明の単一性

<p class="lead">1つの出願に、どこまでの発明をまとめて入れられるか。キーワードは「特別な技術的特徴」。実はこれ、進歩性の考え方と深くつながっています。</p>

::: tip ざっくり言うと
- 1つの出願にまとめられるのは、**同一の又は対応する特別な技術的特徴**を持つ発明のグループ
- 特別な技術的特徴＝**先行技術に対する貢献**を示す技術的特徴
- 先行技術に見つかったり、周知技術の付加・単なる設計変更だったりすると、特別な技術的特徴ではなくなる
- 37条違反は拒絶理由だが、**無効理由ではない**
:::

::: info 原文（基準 II-3 3.(1)）
審査官は、発明の単一性の要件を、特許請求の範囲に記載された二以上の発明が同一の又は対応する特別な技術的特徴を有しているか否かによって判断する(注1)。<br>
ここで、「特別な技術的特徴」とは、発明の先行技術(注2)に対する貢献(先行技術との対比において発明が有する技術上の意義)を明示する技術的特徴を意味する。
:::

## 特別な技術的特徴が否定される場合

::: info 原文（基準 II-3 3.(2)）
ここで、「発明の先行技術に対する貢献をもたらすものでないことが明らかとなった場合」とは、次の(i)から(iii)までのいずれかに該当する場合である。<br>
(i) 「特別な技術的特徴」とされたものが先行技術の中に発見された場合<br>
(ii) 「特別な技術的特徴」とされたものが一の先行技術に対する周知技術、慣用技術の付加、削除、転換等であって、新たな効果を奏するものではない場合<br>
(iii) 「特別な技術的特徴」とされたものが一の先行技術に対する単なる設計変更であった場合
:::

<div class="example">

例（基準 II-3 3.(3) 例1）

- 請求項1：高分子化合物A（酸素バリアー性のよい透明物質）
- 請求項2：高分子化合物Aからなる食品包装容器
- 高分子化合物Aが先行技術に対する貢献をもたらす特別な技術的特徴で、両方がそれを持っている → **単一性あり**

</div>

::: warning 社内判定では
「この発明の**特別な技術的特徴**（先行技術に対する貢献）は何か」を言葉にできると、

- 進歩性の主張の中心がはっきりする
- 1つの出願にまとめられる範囲（物・製法・用途など）が見えてくる

という一石二鳥の効果があります。判定メモに「本発明の特別な技術的特徴」を1行で書く練習をしてみましょう。
:::
