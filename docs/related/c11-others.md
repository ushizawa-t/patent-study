# C11 その他の制度

<p class="lead">審査基準には、ほかにもいろいろな制度が載っています。日常の判定業務ではあまり出てきませんが、「そういう制度がある」と知っておくと、必要になったときに原文にたどり着けます。</p>

| 制度 | ひとことで | 審査基準 |
|---|---|---|
| 外国語書面出願 | 英語などの外国語で書いた書面で出願し、あとから日本語の翻訳文を出す制度 | 第VII部 |
| 国際特許出願（PCT） | 特許協力条約に基づく国際出願が日本に移行したもの | 第VIII部 |
| 期間補償のための存続期間の延長 | 審査などに時間がかかった場合に、特許権の存続期間を延長する制度（67条2項） | 第IX部 第1章 |
| 医薬品等の存続期間の延長 | 薬機法などの承認のために実施できなかった期間について延長する制度（67条4項） | 第IX部 第2章 |
| 実用新案 | 物品の形状・構造・組合せに係る考案。実体審査なしで登録され、権利行使には技術評価書が必要 | 第X部 |
| 不特許事由（32条） | 公の秩序、善良の風俗又は公衆の衛生を害するおそれがある発明は特許を受けられない | 第III部 第5章 |
| 先願参照出願（38条の3） | 明細書・図面を出す代わりに、先の出願を参照すると主張して出願する制度 | 第VI部 第4章 |

::: info 原文（特許法32条）
公の秩序、善良の風俗又は公衆の衛生を害するおそれがある発明については、第二十九条の規定にかかわらず、特許を受けることができない。
:::

::: tip 実用新案と判定
実用新案技術評価では、新規性・進歩性などについて、特許の審査基準（第III部第2章〜第4章）に**準じて**評価されます（基準 第X部 第2章、HB 附属書C）。なお、実用新案法の進歩性は「きわめて容易に」考案できたかどうかで判断されます（実用新案法3条2項）。
:::
