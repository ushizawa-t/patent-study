# C2 先願（39条）

<p class="lead">同じ発明について、2つ以上の特許出願があったら？ 特許を受けられるのは一番先に出願した人だけ。「一発明一特許」と「先願主義」のルールです。</p>

::: tip ざっくり言うと
- 同じ発明について出願が複数あれば、**最先の出願人だけ**が特許を受けられる
- 比べるのは**請求項同士**（29条の2は明細書全体）
- **出願人が同じでも適用される**（同じ発明に2つの権利は認めない）
- 同じ日の出願同士は**協議**で決める。協議が成立しなければ、どちらも特許を受けられない
:::

## 条文

::: info 原文（特許法39条1項・2項）
同一の発明について異なつた日に二以上の特許出願があつたときは、最先の特許出願人のみがその発明について特許を受けることができる。<br>
2 同一の発明について同日に二以上の特許出願があつたときは、特許出願人の協議により定めた一の特許出願人のみがその発明について特許を受けることができる。協議が成立せず、又は協議をすることができないときは、いずれも、その発明について特許を受けることができない。
:::

::: info 原文（基準 III-4 1.）
なお、出願人が同一である場合であっても、最先の出願のみがその発明について特許を受けることができる。これは、本条の規定の趣旨が一の発明に一の権利を設けることであり、このことは出願人の異同に左右されないためである。
:::

## 「同一」の判断

先願との関係では、相違点がない場合に加えて、次の**実質同一**の場合も「同一」です（基準 III-4 3.2.1）。

| 実質同一の類型 | イメージ |
|---|---|
| (ii-1) 課題解決のための具体化手段における**微差**（周知技術・慣用技術の付加、削除、転換等で、新たな効果を奏さないもの） | 29条の2と同じ考え方 |
| (ii-2) 先願発明の発明特定事項を、本願で**上位概念**として表現した差異 | 先願「バネ」・本願「弾性体」 |
| (ii-3) 単なる**カテゴリー表現上の差異** | 「物」の発明か「方法」の発明か、という表現形式だけの違い |

### 同日出願の場合は「両方向」でチェック

::: info 原文（基準 III-4 3.2.2）
他方、発明Aを先願とし、発明Bを後願としたときに後願発明Bと先願発明Aとが同一であっても、発明Bを先願とし、発明Aを後願としたときに後願発明Aと先願発明Bとが同一でない場合(例えば、発明Aが「バネ」であり、発明Bが「弾性体」である場合)は、審査官は、本願発明と同日出願発明とが「同一」でないと判断する。
:::

## なかったことになる出願

他の出願が**放棄・取下げ・却下**されたとき、または**拒絶査定・拒絶審決が確定**したときは、39条の適用については初めからなかったものとみなされます（39条5項。ただし協議不成立による拒絶の確定は除く）。

## 29条・29条の2が先に使われる

::: info 原文（基準 III-4 4.）
第39条は本願発明と先願発明又は同日出願発明とが同一である場合に適用されるものであり、他の出願の特許(実用新案登録)請求の範囲についての補正により、先願発明又は同日出願発明の内容は、変更される可能性がある。他方、第29条(新規性及び進歩性)を本願に適用する場合の引用発明には、そのような変更の可能性がない。また、第29条の2(拡大先願)により本願を排除できる範囲は、先願の出願当初の明細書、特許(実用新案登録)請求の範囲又は図面であり、第39条よりも広く、補正によって変動することもない。
:::

29条・29条の2・39条の違いは [要件の比較表](/reference/comparison) にまとめています。

::: warning 社内判定では
29条の2は出願人が同じなら適用されませんが、**39条は出願人が同じでも適用されます**。自社で似た発明を複数出願するときは、**請求項が重ならないように**（実質同一も含めて）調整しましょう。特に「先の出願がバネ、後の出願が弾性体」のように、後の出願を**上位概念**にすると実質同一になりえます。
:::
