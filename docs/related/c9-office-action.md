# C9 拒絶理由通知の読み方

<p class="lead">出願後に届く拒絶理由通知書。審査官の「判定結果」が書かれた文書です。読み方がわかると、自分たちの社内判定の精度チェックにもなります。</p>

::: tip ざっくり言うと
- 1回目の拒絶理由通知は必ず「**最初の拒絶理由通知**」
- 最初の拒絶理由通知への応答時の補正によって必要になった拒絶理由**だけ**を通知するときは「**最後の拒絶理由通知**」
- 最後の拒絶理由通知のあとは、補正の目的が制限される
- 進歩性の拒絶理由には「主引用発明・相違点・論理付け」が書いてある。これを分解して読む
:::

## 最初と最後

::: info 原文（基準 I-2-3 3.2.1）
「最初の拒絶理由通知」に対する応答時の補正によって通知することが必要になった拒絶理由のみを通知する拒絶理由通知は、「最後の拒絶理由通知」とする。
:::

例えば、審査した請求項に新しい技術的事項を付加する補正や、請求項を追加する補正をしたことで、**新たに**新規性・進歩性の拒絶理由を通知しなければならなくなった場合に、その旨だけを通知する拒絶理由通知は「最後」になります（基準 I-2-3 3.2.1(1) 例2・例3）。

## 進歩性の拒絶理由の読み方

審査官は、相違点を明確に示したうえで、主引用発明から出発して容易に到達する論理付けを記載します（基準 III-2-3 5.3(1)）。読むときは次の表を埋めてみましょう。

| 読み取る項目 | チェック |
|---|---|
| 対象の請求項 | どの請求項が拒絶されている？ 拒絶理由がない請求項はどれ？ |
| 主引用発明（引用文献1） | 技術分野・課題は本願と近い？ 文献の文脈どおりに認定されている？ |
| 一致点・相違点 | 一致点の認定に誤りはない？ 見落とされた相違点はない？ |
| 副引用発明・周知技術 | 相違点に本当に対応している？ 周知技術の証拠は示されている？ |
| 動機付け | 4つの観点（技術分野・課題・作用機能・示唆）のどれを根拠にしている？ |
| 阻害要因・有利な効果 | 考慮されている？ 明細書に書いた効果で反論できる？ |

## 応答の選択肢

- **意見書**で反論する（認定の誤り、動機付けの不存在、阻害要因、顕著な効果など）
- **補正**で相違点を増やす（明細書に書いてある範囲で）
- **実験成績証明書**で効果を立証する（明細書に書いてある、または推論できる効果に限る）
- **分割出願**で別の範囲を確保する（→ [C10](/related/c10-priority)）

審査官が拒絶理由通知の中で「こう補正すれば拒絶理由が解消する」と**補正の示唆**をしてくれることもあります。ただし、それに従うかどうかは出願人の判断です。

::: info 原文（HB 第XII部 第1章 12103 の事例より）
なお、上記の補正の示唆は、法律的効果を生じさせるものではなく、どのように補正、主張・立証を行うかは、出願人の意思、責任においてなされるべきものである。
:::

::: warning 社内判定では
自社の出願に届いた拒絶理由通知は、**最高の教材**です。

- 社内判定で見つけていた文献と、審査官が引用した文献は同じだった？
- 社内判定で想定した論理付けと、審査官の論理付けは同じだった？

を振り返ると、判定の精度がどんどん上がっていきます。
:::
