# C3 新規性喪失の例外（30条）

<p class="lead">研究員さんが「先週の学会で発表しちゃいました…」と相談に来たら？ すぐにあきらめる必要はありません。一定の条件を満たせば、自分の公開で新規性を失わないことにできる制度があります。</p>

::: tip ざっくり言うと
- 公開から**1年以内**に出願すれば、その公開を「なかったこと」にできる
- 対象は、**権利者の意に反する公開**（1項）と、**権利者の行為に起因する公開**（2項）
- 2項を使うには、出願と**同時に**その旨の書面を出し、出願から**30日以内**に「証明する書面」を出す
- 公開が複数あるときは、原則としてそれぞれについて証明が必要
- ただし、例外が認められるのは**その公開についてだけ**。その間に**他人が**同じ発明を公開・出願していたら守られない
:::

## 条文

::: info 原文（特許法30条）
特許を受ける権利を有する者の意に反して第二十九条第一項各号のいずれかに該当するに至つた発明は、その該当するに至つた日から一年以内にその者がした特許出願に係る発明についての同項及び同条第二項の規定の適用については、同条第一項各号のいずれかに該当するに至らなかつたものとみなす。<br>
2 特許を受ける権利を有する者の行為に起因して第二十九条第一項各号のいずれかに該当するに至つた発明(発明、実用新案、意匠又は商標に関する公報に掲載されたことにより同項各号のいずれかに該当するに至つたものを除く。)も、その該当するに至つた日から一年以内にその者がした特許出願に係る発明についての同項及び同条第二項の規定の適用については、前項と同様とする。<br>
3 前項の規定の適用を受けようとする者は、その旨を記載した書面を特許出願と同時に特許庁長官に提出し、かつ、第二十九条第一項各号のいずれかに該当するに至つた発明が前項の規定の適用を受けることができる発明であることを証明する書面(次項において「証明書」という。)を特許出願の日から三十日以内に特許庁長官に提出しなければならない。<br>
4 証明書を提出する者がその責めに帰することができない理由により前項に規定する期間内に証明書を提出することができないときは、同項の規定にかかわらず、その理由がなくなつた日から十四日(在外者にあつては、二月)以内でその期間の経過後六月以内にその証明書を特許庁長官に提出することができる。
:::

::: info 原文（基準 III-2-5 1.）
｢公開された発明｣について発明の新規性喪失の例外規定が適用されると、特許出願に係る発明の新規性及び進歩性の要件の判断において、その｢公開された発明｣は、引用発明とはならない。
:::

2項のかっこ書きに注意：**特許公報などに掲載されたことによる公開は対象外**です（自分の出願が公開されたから、という理由では使えません）。

## 1項と2項の違い

| | 1項：意に反する公開 | 2項：行為に起因する公開 |
|---|---|---|
| 典型例 | 守秘義務があるのに相手が公開した／窃盗・詐欺・強迫などの不正な手段で公開された | 学会発表、論文掲載、展示会出展、製品販売、記者会見、ウェブ掲載 |
| 期間 | 公開から1年以内に出願 | 公開から1年以内に出願 |
| 手続 | 意見書・上申書などで**合理的に説明** | 出願と同時に**その旨の書面**、出願から**30日以内に証明する書面** |

1年という期間は、**平成29年12月9日以降に公開された発明**に適用されます（それより前は6か月でした。改正経緯は HB 3230〜3234）。

## 証明する書面の書式

::: info 原文（基準 III-2-5 2.3.1 ｢証明する書面｣の書式）
発明の新規性喪失の例外規定の適用を受けるための証明書<br>
１．公開の事実<br>
① 公開日<br>
② 公開場所<br>
③ 公開者<br>
④ 公開された発明の内容(証明する対象を特定し得る程度に記載)<br>
２．特許を受ける権利の承継等の事実<br>
① 公開された発明の発明者<br>
② 発明の公開の原因となる行為時の特許を受ける権利を有する者(行為時の権利者)<br>
③ 特許出願人(願書に記載された者)<br>
④ 公開者<br>
⑤ 特許を受ける権利の承継について(①の者から②の者を経て③の者に権利が譲渡されたこと)<br>
⑥ 行為時の権利者と公開者との関係等について<br>
(②の者の行為に起因して、④の者が公開をしたこと等を記載)<br>
上記記載事項が事実に相違ないことを証明します。
:::

## 公開が複数あるとき

原則として、**それぞれの公開**について証明する書面が必要です。ただし、証明書で適用が認められた公開と<strong>同一（とみなせる）</strong>で、それと**密接に関連する公開行為**による（または権利者等以外の者による）、**それ以降**の公開であれば、証明書がなくても適用を受けられます（基準 III-2-5 4.2）。

| 証明書なしでも認められる例（基準より） |
|---|
| 同じ学会の巡回講演で、同じ内容を複数回講演した場合の2回目以降 |
| 出版社のウェブサイトに論文が先行掲載され、その後同じ出版社の雑誌に掲載された場合 |
| 学会発表のあとに、その概略を書いた講演要旨集が発行された場合 |
| 同じ取引先へ同じ商品を複数回納品した場合の2回目以降 |
| テレビ・ラジオ放送と、その再放送 |
| 権利者が商品を販売し、それを入手した第三者がウェブサイトに掲載した場合 |
| 権利者の記者会見と、その内容を載せた新聞 |

::: danger よくある間違い
順番が逆だと認められないことが多いです。**講演要旨集が先に発行され、そのあと学会発表**した場合、要旨集は発表内容の「概略」なので、あとの学会発表と「同一」とはいえないことが多く、学会発表についても30日以内に証明書を出しておかないと適用されません（基準 III-2-5 4.2 例3 の注）。
:::

## 優先権・分割などのときの「出願をした日」

| 出願の種類 | 「公開から1年以内に出願したか」の基準日 |
|---|---|
| 国内優先権の主張を伴う出願 | 発明が先の出願の当初明細書等に書いてあれば**優先日**（ただし先の出願で証明書を出していなければ後の出願の日） |
| パリ条約による優先権の主張を伴う出願 | **日本への出願日** |
| 分割出願・変更出願など | 原出願の日（ただし原出願で証明書を出していなければ現実の出願日） |

::: warning 社内判定では
30条は「最後の手段」と考えましょう。

- 例外が認められても、その間に**第三者が同じ発明を独自に公開・出願**していたら、それには対抗できません
- **外国では**日本と同じように救済されるとは限りません（国ごとに制度が違います）
- 証明書の**30日の期限**は短いので、学会発表の予定があれば、**発表前に出願**できないか早めに調整するのが一番です

研究員さんには「発表・投稿・展示・サンプル提供の**前に**知財部に相談してください」と日頃から伝えておきましょう。
:::
