# C1 拡大先願（29条の2）

<p class="lead">自分より先に出願されていたけれど、自分の出願の時点ではまだ公開されていなかった他人の出願。これに書かれていた発明と同じ発明は、特許を受けられません。それが「拡大先願」です。</p>

::: tip ざっくり言うと
- 本願より**前に出願**され、本願より**後に公開**された他の出願の、**当初明細書等の全体**に書かれた発明と同じ発明は、特許を受けられない
- 「同じ」には**実質同一**（周知技術の付加などの微差）も含む。進歩性までは問わない
- **発明者が同じ**、または本願の出願時に**出願人が同じ**なら適用されない
- 39条（先願）が請求項同士を比べるのに対し、29条の2は**明細書全体**が対象なので「拡大」先願と呼ぶ
:::

## 条文

::: info 原文（特許法29条の2）
特許出願に係る発明が当該特許出願の日前の他の特許出願又は実用新案登録出願であつて当該特許出願後に第六十六条第三項の規定により同項各号に掲げる事項を掲載した特許公報(以下「特許掲載公報」という。)の発行若しくは出願公開又は実用新案法(昭和三十四年法律第百二十三号)第十四条第三項の規定により同項各号に掲げる事項を掲載した実用新案公報(以下「実用新案掲載公報」という。)の発行がされたものの願書に最初に添付した明細書、特許請求の範囲若しくは実用新案登録請求の範囲又は図面(第三十六条の二第二項の外国語書面出願にあつては、同条第一項の外国語書面)に記載された発明又は考案(その発明又は考案をした者が当該特許出願に係る発明の発明者と同一の者である場合におけるその発明又は考案を除く。)と同一であるときは、その発明については、前条第一項の規定にかかわらず、特許を受けることができない。ただし、当該特許出願の時にその出願人と当該他の特許出願又は実用新案登録出願の出願人とが同一の者であるときは、この限りでない。
:::

長い条文ですが、分解すると次の4つの要件になります。

::: info 原文（基準 III-3 2.(1)(2)）
(1) 他の出願が満たすべき形式的要件<br>
(i) 他の出願が本願の出願日の前日以前に出願されたものであること。<br>
(ii) 他の出願が本願の出願後に出願公開等がされたものであること(注)。<br>
(iii) 他の出願の発明者が本願の請求項に係る発明の発明者と同一でないこと。<br>
(iv) 他の出願の出願人が本願の出願時において、本願の出願人と同一でないこと。<br>
(注) 本願の出願前に、他の出願の出願公開等がされていれば、第29条の2は適用されず、出願公開等に係る公報により公開された発明を第29条第1項第3号の発明として同条第1項又は第2項が適用される。<br>
(2) 本願に係る発明と、他の出願の当初明細書等に記載された発明等とが同一であること(実質的要件)。
:::

## タイムラインで見てみよう

```
 他の出願         本願           他の出願の公開
  出願            出願
───●─────────────●─────────────────●──────→ 時間
   │             │                 │
   └─ 本願の出願日の前日以前 ──┘                 │
                 └─ 本願より後に公開 ─────────┘

→ 他の出願の当初明細書等に書いてある発明と「同一」なら、本願は拒絶
（ただし、発明者が同じ・本願出願時に出願人が同じなら適用なし）
```

もし他の出願が本願の出願**前に**公開されていれば、それは普通の刊行物（29条1項3号）として、新規性・進歩性の引用文献になります。

## 「同一」の判断

::: info 原文（基準 III-3 3.2）
審査官は、本願の請求項に係る発明と、引用発明とを対比した結果、以下の(i)又は(ii)の場合は、両者をこの章でいう「同一」と判断する。<br>
(i) 本願の請求項に係る発明と引用発明との間に相違点がない場合<br>
(ii) 本願の請求項に係る発明と引用発明との間に相違点がある場合であっても、両者が実質同一である場合<br>
ここでの実質同一とは、本願の請求項に係る発明と引用発明との間の相違点が課題解決のための具体化手段における微差(周知技術、慣用技術(注)の付加、削除、転換等であって、新たな効果を奏するものではないもの)である場合をいう。
:::

新規性より少し広い（微差も含む）けれど、**進歩性ほど広くはない**（容易想到までは含まない）、という位置づけです。

## 発明者同一・出願人同一の判断

| 要件 | 判断のポイント |
|---|---|
| **発明者同一** | 願書に記載された発明者の**全員が完全に一致**（改姓など実質的に同一人と判断できる場合を含む）していれば同一。一部だけ重なっていても「同一ではない」 |
| **出願人同一** | **本願の出願時点**で判断。出願人の**全員が完全に一致**していれば同一。名義変更届、改称、合併などの一般承継も考慮される |

::: info 原文（基準 III-3 4.2）
なお、他の出願の当初明細書等に記載されている事項がその後の補正により削除されたとしても、そのことは、第29条の2の規定の適用に影響しない。
:::

::: warning 社内判定では（自社出願との関係）
29条の2は、**自社の未公開出願**との関係でとても重要です。

- 自社の先の出願（未公開）と後の出願で**出願人が同じ**なら、29条の2は**適用されません**。改良発明を後から出願しても、先の出願の明細書に書いた内容で拒絶されることはありません（ただし請求項同士が同一なら [39条](/related/c2-prior-app) の問題）
- ところが、**共同出願**だと要注意。先の出願が「自社＋A社」、後の出願が「自社だけ」なら出願人は**全員一致しない**ので、29条の2が適用されえます
- 発明者についても、**全員が一致**しないと「同一」になりません

社内の未公開出願（出願から公開までの約1年6か月）は、外部のデータベースでは見つかりません。**社内の出願リストも確認**する習慣をつけましょう。
:::
