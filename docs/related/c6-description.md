# C6 記載要件

<p class="lead">新規性・進歩性で勝負するには、明細書の「書き方」もしっかりしている必要があります。進歩性の主張の根拠を、ちゃんと明細書に用意しておけるようにしましょう。</p>

::: tip ざっくり言うと
| 要件 | 条文 | ひとことで |
|---|---|---|
| 実施可能要件 | 36条4項1号 | 当業者が**実施できる**ように明細書を書く |
| サポート要件 | 36条6項1号 | 請求項は、明細書に**書いた範囲を超えない** |
| 明確性要件 | 36条6項2号 | 請求項は**明確**に書く |
| 簡潔性要件 | 36条6項3号 | 請求項は**簡潔**に書く |
:::

## サポート要件

::: info 原文（基準 II-2-2 1.）
特許法第36条第6項第1号は、請求項に係る発明が発明の詳細な説明に記載した範囲を超えるものであってはならない旨を規定している。<br>
発明の詳細な説明に記載していない発明を特許請求の範囲に記載することになれば、公開されていない発明について権利が発生することになるからである。
:::

サポート要件違反の類型（基準 II-2-2 2.2）：

1. 請求項に書いた事項が、発明の詳細な説明に**記載も示唆もされていない**（例：請求項は数値限定なのに、明細書に具体的な数値が何もない）
2. 請求項と発明の詳細な説明の**用語が不統一**で、対応関係が不明瞭
3. 出願時の技術常識に照らしても、明細書の内容を請求項の範囲まで**拡張・一般化できない**
4. 請求項に、発明の詳細な説明に記載された**課題を解決するための手段が反映されていない**

::: info 原文（基準 II-2-2 2.2(3)a）
請求項は、発明の詳細な説明に記載された一又は複数の具体例に対して拡張ないし一般化した記載とすることができる。発明の詳細な説明に記載された範囲を超えないものとして拡張ないし一般化できる程度は、各技術分野の特性により異なる。
:::

## 実施可能要件・明確性要件

- **実施可能要件**：物の発明なら「作れて使える」、方法の発明なら「使える」ように、発明の詳細な説明を書く必要があります（基準 II-1-1）
- **明確性要件**：請求項から発明が明確に把握できる必要があります。機能・特性で特定した請求項や、製造方法で物を特定した請求項（プロダクト・バイ・プロセス）は、明確性の観点からも注意が必要です（基準 II-2-3 4.）

::: warning 社内判定では（進歩性とのつながり）
- 進歩性を「顕著な効果」で主張したいなら、その効果が**明細書に書いてある**必要があります（[B9](/core/b9-inventive-positive)）
- 新規性・進歩性を確保するために請求項を絞るときも、その限定が<strong>明細書に書いてある（サポートされている）</strong>必要があります
- 広い請求項にしたいなら、それを支える**複数の実施例**が必要です

判定の段階で「何を明細書に書いておくべきか」を研究員さんに伝えることが、後々の権利化を大きく左右します。
:::
