# C8 補正・新規事項・除くクレーム

<p class="lead">拒絶理由通知を受けたら、請求項を補正して対応します。ただし補正には「新規事項を追加してはいけない」という大原則があります。判定の段階で、将来の補正の「のりしろ」を明細書に用意しておきましょう。</p>

::: tip ざっくり言うと
- 補正は「**当初明細書等に記載した事項の範囲内**」でしかできない（新たな技術的事項を導入しない）
- 「当初明細書等に記載した事項」＝当業者が明細書等の**全ての記載を総合**して導かれる技術的事項
- **除くクレーム**：引用発明と偶然重なる部分だけを「（ただし、〜を除く。）」と除く補正。条件を満たせば許される
- 最後の拒絶理由通知のあとは、補正の目的が制限される（請求項の削除、限定的減縮、誤記の訂正、明瞭でない記載の釈明）
:::

## 新規事項の判断

::: info 原文（基準 IV-2 2.）
審査官は、補正が「当初明細書等に記載した事項」との関係において、新たな技術的事項を導入するものであるか否かにより、その補正が新規事項を追加する補正であるか否かを判断する。「当初明細書等に記載した事項」とは、当業者によって、当初明細書等の全ての記載を総合することにより導かれる技術的事項である。
:::

これは「ソルダーレジスト」大合議判決（知財高判平成20年5月30日）の考え方に基づいています。

## 除くクレーム

::: info 原文（基準 IV-2 3.3.1(4)）
「除くクレーム」とは、請求項に記載した事項の記載表現を残したままで、請求項に係る発明に包含される一部の事項のみをその請求項に記載した事項から除外することを明示した請求項をいう。<br>
「除くクレーム」とする補正であっても、新たな技術的事項を導入するものではない場合には、補正は許される。
:::

通常、許される典型例は次の2つです。

::: info 原文（基準 IV-2 3.3.1(4)）
(i) 請求項に係る発明が引用発明と偶然重なるために新規性等(第29条第1項第3号、第29条の2又は第39条)が否定されるおそれがある場合に、その重なりのみを除くことにより、請求項に係る発明と技術的思想として顕著に異なる発明を含まないことを明らかにする補正<br>
(ii) 請求項に係る発明が、「ヒト」を包含しているために、第29条第1項柱書の要件を満たさない、又は第32条に規定する不特許事由に該当する場合において、「ヒト」のみを除く補正
:::

<div class="example">

例（基準 IV-2 例4）

- 補正前：化合物A、及び炭素数4以下のモノカルボン酸又はその塩を含有する**動物用経口投与組成物**（飼料の保存性を高める）
- 引用発明：化合物Aと**フルオロ酢酸ナトリウム**（猛毒）を含有する、**害獣を殺傷する**ための経口投与組成物
- 補正後：「（ただし、フルオロ酢酸ナトリウムを除く。）」を追加
- → 技術的思想が顕著に異なる発明との偶然の重なりだけを除くもので、許される

</div>

::: danger 除くクレームで進歩性は救えるか？
基本的には難しいです。本来進歩性がない発明が、除くクレームで進歩性を持つように変わるなら、それは新たな技術的事項の導入と判断されえます（基準 IV-2 3.3.1(4) 留意事項(2)）。除くクレームは主に「**偶然の重なり**」を解消するための道具だと考えましょう。除くクレームとする補正がされた出願の審査上の注意点は HB 第XII部にまとまっています。
:::

## 補正できる時期と制限

| 時期 | 主な制限 |
|---|---|
| 出願から最初の拒絶理由通知まで | 新規事項の追加禁止 |
| 最初の拒絶理由通知の指定期間内 | 新規事項の追加禁止、発明の特別な技術的特徴の変更禁止（シフト補正） |
| 最後の拒絶理由通知の指定期間内・拒絶査定不服審判の請求と同時 | 上に加えて、**目的の制限**（請求項の削除、限定的減縮、誤記の訂正、明瞭でない記載の釈明）。限定的減縮の場合は**独立特許要件**も |

::: warning 社内判定では
判定で見つけた先行技術を踏まえて、

- 将来、請求項を絞る**候補となる特徴**（追加の構成、好ましい数値範囲、下位概念）
- その**根拠になる実施例・データ**

を明細書に**あらかじめ書いておく**ように研究員さん・明細書担当者に伝えましょう。出願後に書き足すことはできません。
:::
