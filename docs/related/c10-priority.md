# C10 優先権・分割

<p class="lead">出願したあとに改良が生まれたら？ 1つの出願から別の権利を取りたくなったら？ 国内優先権と分割出願は、判定後の出願戦略でよく使う道具です。</p>

::: tip ざっくり言うと
- **国内優先権**：先の出願から**1年以内**に、改良を加えてまとめて出願できる。先の出願に**書いてあった部分**は先の出願の時を基準に新規性・進歩性などを判断
- **パリ条約の優先権**：外国の最初の出願を基礎に、日本へ出願するときなどに使う
- **分割出願**：もとの出願の一部を新しい出願にする。適法なら**もとの出願の時**にしたものとみなされる
:::

## 国内優先権

::: info 原文（基準 V-2 1.）
特許法第41条に規定される特許出願等に基づく優先権(以下この章において「国内優先権」という。)制度とは、既に出願した自己の特許出願又は実用新案登録出願(以下この章において「先の出願」という。)の発明を含めて包括的な発明としてまとめた内容を、優先権を主張して特許出願(以下この章において「後の出願」という。)をする場合には、その包括的な特許出願に係る発明のうち、先の出願の出願当初の明細書、特許請求の範囲又は図面(以下この章において「当初明細書等」という。)に記載されている発明について、新規性、進歩性等の判断に関し、出願の時を先の出願の時とするという優先的な取扱いを認めるものである。
:::

主なポイントです（基準 V-2 2.）。

- 主張できるのは、**先の出願の出願人**（後の出願の時点で出願人が同一）
- 期間は、原則として**先の出願の日から1年**
- 分割出願・変更出願などは、先の出願にできない
- 効果が及ぶのは、先の出願の当初明細書等に**記載されている発明**についてだけ。新規性・進歩性・拡大先願・30条などの判断で、先の出願の時にされたものとみなされる

```
 先の出願（基本発明A）        後の出願（A＋改良B）
───●─────────────────────●──────→
   │←────── 1年以内 ──────→│
 Aの基準時                     Bの基準時
```

::: danger よくある間違い
「優先権を主張すれば、後の出願全体が先の出願日で判断される」は間違い。**あとから追加した改良B**は、後の出願の時が基準です。先の出願と後の出願の間に自社が改良Bを発表していたら、Bの新規性に影響します（30条の検討が必要）。
:::

## 分割出願

::: info 原文（基準 VI-1-1 1.）
特許法第44条は、特許出願の分割に関する規定である。同条は、出願人が二以上の発明を包含する特許出願の一部を新たな特許出願とすることができる旨を規定している。また、同条は、特許出願の分割が適法になされた場合には、新たな特許出願は、もとの特許出願の時にしたものとみなされる旨を規定している。
:::

分割できる時期は、①明細書等を補正できる時期、②特許査定の謄本送達日から30日以内、③最初の拒絶査定の謄本送達日から3月以内、です（基準 VI-1-1 2.1.2）。

::: warning 社内判定では
- 基本発明を早めに出願し、研究の進展にあわせて**国内優先権で改良を取り込む**のは定番の戦略です。そのぶん判定の段階で「**いま出せる範囲**」と「**1年以内に追加したい範囲**」を整理しておくと便利です
- 先の出願と後の出願の間の**学会発表・製品発表**には特に注意しましょう
:::
