# B3 ウェブ上の先行技術

<p class="lead">最近の先行技術調査では、論文や特許だけでなく、ウェブページ・動画・データベースもよく出てきます。ネット上の情報はどんなときに「公衆に利用可能」になるのか、見ていきましょう。</p>

::: tip ざっくり言うと
- ネット上の情報は「**検索やリンクでたどり着けて、アクセス制限がない**」なら公衆に利用可能
- パスワードや料金が必要でも、**誰でも手続すれば差別なく**見られるならOK
- 社内システム、アドレス非公開、ごく短時間だけの公開などは「公衆に利用可能」とは言いにくい
- ネットの情報は書き換えやすいので、**掲載時期・掲載内容の信頼性**にも注意
:::

## 「電気通信回線を通じて公衆に利用可能」とは

::: info 原文（基準 III-2-3 3.1.2）
「電気通信回線を通じて公衆に利用可能となった発明」とは、電気通信回線(注1)を通じて不特定の者が見得るような状態に置かれた(注2)ウェブページ等(注3)に掲載された発明をいう。<br>
(注1) 「回線」とは、一般に往復の通信路で構成された、双方向に通信可能な伝送路を意味する。一方向にしか情報を送信できない放送は、「回線」には含まれない。双方向からの通信を伝送するケーブルテレビ等は、「回線」に該当する。<br>
(注2) 現実に誰かがアクセスしたという事実を必要としない。具体的には、以下の(i)及び(ii)の両方を満たすような場合は、公衆に利用可能となった(不特定の者が見得る状態に置かれた)ものといえる。<br>
(i) インターネットにおいて、公知のウェブページ等からリンクをたどることで到達でき、検索エンジンに登録され、又はアドレス(URL)が公衆への情報伝達手段(例えば、広く一般的に知られている新聞、雑誌等)に載っていること。<br>
(ii) 公衆からのアクセス制限がなされていないこと。<br>
(注3) 「ウェブページ等」とは、インターネット等において情報を掲載するものをいう。「インターネット等」とは、インターネット、商用データベース、メーリングリスト等の電気通信回線を通じて情報を提供するものをいう。
:::

テレビやラジオの「放送」は一方向なので「回線」ではない、というのはちょっとした豆知識です（ただし放送で知られた内容は「公然知られた発明」になりえます）。

## 公衆に利用可能？ 判定してみよう（HB 3209）

| 状況 | 公衆に利用可能？ |
|---|---|
| 検索エンジンに登録されていて検索できる | ○ |
| 学会やニュースサイトからリンクされている／URL が新聞・雑誌に載っている | ○ |
| パスワードが必要だが、**誰でも手続すれば差別なく**パスワードを入手できる（有料でも可） | ○ |
| 閲覧が有料だが、**料金を払えば誰でも**アクセスできる | ○ |
| アドレスが公開されておらず、偶然でなければたどり着けない | × |
| 特定の団体・企業の構成員に限られ、部外秘扱い（社員専用の社内システムなど） | × |
| 通常解読できない暗号化がされている（誰でも解読ツールを入手できる場合を除く） | × |
| ごく短時間だけ公開されていた | × |

## 掲載時期・掲載内容は信用できる？

ネット上の情報は書き換えが簡単です。そこで、引用するには「**表示されている掲載時期に、その内容のとおりに掲載されていた**」ことが必要です。

::: info 原文（HB 3210(1)）
以下の(i)から(iv)までのようなウェブページ等は、通常、そのような疑義が極めて低い。このようなウェブページ等について、審査官がアクセスした時に掲載されている内容は、そのウェブページ等で示されている掲載時期に掲載されていたものと審査官は推認する。<br>
(i) 刊行物等を長年出版している出版社のウェブページ<br>
(ii) 学術機関(学会、大学等)のウェブページ<br>
(iii) 国際機関(標準化機関等)のウェブページ<br>
(iv) 公的機関(省庁等)のウェブページ
:::

一方、個人のウェブページなどで疑わしいものは、問い合わせ先に照会して確認し、疑いが晴れなければ引用しません（HB 3210(2)）。

::: details 出願人が「ネットの情報だから信用できない」と反論したら？
具体的な根拠のない「ネットだから疑わしい」という反論だけでは採用されません。具体的な根拠を示して反論があり、疑義が生じた場合は、審査官が掲載・保全の権限と責任を持つ人に確認を求めます（基準 III-2-3 3.1.2(2)）。
:::

### 公開日が書いていないページは？

ウェブアーカイブ（保存日時がわかるもの）や、サイト内の「新着情報」ページのように**別の証拠から公開日がわかる**場合は、それを使って公開日を認定できます（HB 3208）。

::: warning 社内判定では
- 社内での先行技術調査でも、製品紹介ページ・技術ブログ・動画・プレスリリースは立派な先行技術になりえます。**公開日の証拠**（ページ上の日付、アーカイブ）をセットで記録しておきましょう
- 逆に、自社の技術情報を**ウェブに出すとき**も同じルールで公知になります。研究員さんが技術ブログや SNS で発信していないかも確認ポイントです
- **未公開の発明をネットで検索するとき**は、検索語そのものから発明内容が外部に漏れるリスクがあります（HB 3213）。特に「一般的な用語の新しい組合せ」や「公知の物の新しい用途」で検索するときは要注意です
:::
