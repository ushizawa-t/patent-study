# B9 進歩性③ 肯定する方向の要素

<p class="lead">論理付けができそうでも、まだ終わりではありません。「予想以上にすごい効果がある」「そもそも組み合わせるのを邪魔する事情がある」——そんな、進歩性を後押しする事情を見ていきます。</p>

::: tip ざっくり言うと
- **有利な効果**：引用発明と比べて有利な効果は、進歩性を肯定する方向に働く。特に**予測を超えた顕著な効果**は有力
- 効果は<strong>明細書に書いてある（または推論できる）</strong>ものしか考慮されない
- **阻害要因**：副引用発明を主引用発明に当てはめると、目的に反する・機能しなくなる・文献が排除している、など
- どちらも「あれば必ず進歩性あり」ではなく、**程度**も含めて総合評価する
:::

## 1. 引用発明と比較した有利な効果

::: info 原文（基準 III-2-2 3.2.1）
引用発明と比較した有利な効果は、進歩性が肯定される方向に働く要素である。このような効果が明細書、特許請求の範囲又は図面の記載から明確に把握される場合は、審査官は、進歩性が肯定される方向に働く事情として、これを参酌する。ここで、引用発明と比較した有利な効果とは、発明特定事項によって奏される効果(特有の効果)のうち、引用発明の効果と比較して有利なものをいう。
:::

### 有利な効果があっても、進歩性が否定されることはある

::: info 原文（基準 III-2-2 3.2.1(1)）
請求項に係る発明が、引用発明と比較した有利な効果を有している場合は、審査官は、その効果を参酌して、当業者が請求項に係る発明に容易に想到できたことの論理付けを試みる。そして、請求項に係る発明が引用発明と比較した有利な効果を有していても、当業者が請求項に係る発明に容易に想到できたことが、十分に論理付けられた場合は、請求項に係る発明の進歩性は否定される。
:::

### 予測を超えた顕著な効果は「有力な事情」

::: info 原文（基準 III-2-2 3.2.1(1)）
しかし、引用発明と比較した有利な効果が、例えば、以下の(i)又は(ii)のような場合に該当し、技術水準から予測される範囲を超えた顕著なものであることは、進歩性が肯定される方向に働く有力な事情になる。<br>
(i) 請求項に係る発明が、引用発明の有する効果とは異質な効果を有し、この効果が出願時の技術水準から当業者が予測することができたものではない場合<br>
(ii) 請求項に係る発明が、引用発明の有する効果と同質の効果であるが、際だって優れた効果を有し、この効果が出願時の技術水準から当業者が予測することができたものではない場合
:::

| | 意味 | イメージ |
|---|---|---|
| **異質な効果** | 引用発明にはない、種類の違う効果 | 強度を上げるつもりが、なぜか耐食性も劇的に上がった |
| **同質だが際立って優れた効果** | 同じ種類の効果だが、レベルが段違い | 審査基準の例：モチリンの活性が引用発明の**6〜9倍** |

特に、**物の構造から効果を予測しにくい分野**（化学・材料・バイオなど）では、効果が進歩性判断の重要な事情になります（選択発明など → [B11](/core/b11-special-claims)）。

### ヒト結膜肥満細胞安定化剤事件（最高裁）

::: info 原文（HB 3202 より　最三小判令和元年8月27日）
原審は，結局のところ，本件各発明の効果，取り分けその程度が，予測できない顕著なものであるかについて，優先日当時本件各発明の構成が奏するものとして当業者が予測することができなかったものか否か，当該構成から当業者が予測することができた範囲の効果を超える顕著なものであるか否かという観点から十分に検討することなく，本件化合物を本件各発明に係る用途に適用することを容易に想到することができたことを前提として，本件化合物と同等の効果を有する本件他の各化合物が存在することが優先日当時知られていたということのみから直ちに，本件各発明の効果が予測できない顕著なものであることを否定して本件審決を取り消したものとみるほかなく，このような原審の判断には，法令の解釈適用を誤った違法があるといわざるを得ない。
:::

ポイントは、効果の顕著性は「**論理付けできるとされた構成から予測できる範囲を超えるか**」で判断する、ということです。「同じくらいの効果を持つ別の化合物が知られていた」というだけで、顕著な効果を否定してはいけません（HB 3202）。

### 意見書で主張できる効果には条件がある

::: info 原文（基準 III-2-2 3.2.1(2)）
以下の(i)又は(ii)の場合は、審査官は、意見書等において主張、立証(例えば、実験結果の提示)がなされた、引用発明と比較した有利な効果を参酌する。<br>
(i) その効果が明細書に記載されている場合<br>
(ii) その効果は明細書に明記されていないが、明細書又は図面の記載から当業者がその効果を推論できる場合<br>
しかし、審査官は、意見書等で主張、立証がなされた効果が明細書に記載されておらず、かつ、明細書又は図面の記載から当業者が推論できない場合は、その効果を参酌すべきでない。
:::

::: warning 社内判定では（とても大事！）
出願したあとで「実はこんなすごい効果があるんです」と言っても、**明細書に書いていなければ（推論もできなければ）考慮してもらえません**。

だから判定の段階で、研究員さんに

- 従来品・比較例と比べた**効果のデータ**はあるか
- 効果が出るのは**数値範囲のどこからどこまで**か（範囲の外ではどうなるか）
- 想定外の**別の効果**（異質な効果）は出ていないか

を確認し、**明細書に書いてもらう**ことがとても重要です。判定は「特許になるか」を見るだけでなく、「特許になるように準備する」仕事でもあります。
:::

## 2. 阻害要因

::: info 原文（基準 III-2-2 3.2.2(1)）
副引用発明を主引用発明に適用することを阻害する事情があることは、論理付けを妨げる要因(阻害要因)として、進歩性が肯定される方向に働く要素となる。ただし、阻害要因を考慮したとしても、当業者が請求項に係る発明に容易に想到できたことが、十分に論理付けられた場合は、請求項に係る発明の進歩性は否定される。
:::

阻害要因の典型は次の4つです。

| 類型 | 審査基準の例 |
|---|---|
| (i) 当てはめると主引用発明が**目的に反する**ものになる | 水道水のオゾン滅菌で、**高価な気液接触装置を避ける**ことが目的の主引用発明に、オゾンガスを取り出して再注入する（気液接触が必要な）副引用発明を適用する |
| (ii) 当てはめると主引用発明が**機能しなくなる** | ベーンポンプのシールに、所定形状のガスケットを使うと**隙間ができてポンプとして機能しない** |
| (iii) 主引用発明がその適用を**排斥している** | かしめ固定を採用した膨張弁の文献が、ねじ止め（螺着）は**コストがかかり面倒だから採用しない**と書いている |
| (iv) 副引用発明が、文献中で**劣った例**として書かれている | 複数の加熱態様のうち「全部を温度aで運転する態様」が、**染斑が出やすい態様**として記載されている |

また、引用発明が記載された文献の中に、**請求項の発明に容易に想到することを妨げるような記載**があることも阻害要因になります（3.2.2(2)）。

::: info 原文（基準 III-2-2 3.2.2(1)）
審査官は、以下のような阻害要因があるといえる場合であっても、進歩性が肯定される方向に働く要素としての程度には差異があることに留意する。
:::

<div class="example">

附属書A 進歩性 事例1（周期的分極反転領域を持つ基板の製造方法）

- 引用発明は「**MgOを添加すると**分極反転の制御性が悪くなる」という問題の解決を課題にしていた
- 周知技術として「MgOを添加して光透過率を上げる」ことは知られていて、**動機付けはある**
- でも、MgOを添加するのは**引用発明の目的に反する** → 阻害要因あり
- 阻害要因は動機付けを考慮してもなお適用を妨げる程度 → **進歩性あり**

</div>

::: warning 社内判定では
研究員さんが「業界ではこれは**やってはいけない**と言われていた」「この文献には**逆の方向がよい**と書いてあった」と話していたら、それは阻害要因のサインです。根拠となる文献をメモしておき、明細書の背景技術や意見書で使えるようにしておきましょう。
:::
