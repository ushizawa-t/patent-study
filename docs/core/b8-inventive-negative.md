# B8 進歩性② 否定する方向の要素

<p class="lead">「容易に思いつける」という理屈を組み立てる材料です。動機付け・設計変更等・単なる寄せ集め。審査基準の例がとてもわかりやすいので、ひとつずつ見ていきましょう。</p>

::: tip ざっくり言うと
- **動機付け**：主引用発明に副引用発明をくっつけようと思うきっかけ。4つの観点を**総合的に**考える
- **設計変更等**：材料の選択、数値の最適化、均等物への置換、設計的事項。普通の創作能力の範囲
- **単なる寄せ集め**：それぞれ公知で、互いに機能的に関係しないものを並べただけ
:::

## 主引用発明の選び方

まず出発点を選びます。

::: info 原文（基準 III-2-2 3.3(2)）
審査官は、主引用発明として、通常、請求項に係る発明と、技術分野又は課題(注1)が同一であるもの又は近い関係にあるものを選択する。<br>
請求項に係る発明とは技術分野又は課題が大きく異なる主引用発明を選択した場合には、論理付けは困難になりやすい。
:::

ハンドブックでは、最適の主引用発明を選ぶために、**請求項に係る発明や主引用発明の実施の形態も勘案する**とされています（HB 3203）。

## 1. 動機付け

::: info 原文（基準 III-2-2 3.1.1）
主引用発明(A)に副引用発明(B)を適用したとすれば、請求項に係る発明(A+B)に到達する場合(注1)には、その適用を試みる動機付けがあることは、進歩性が否定される方向に働く要素となる。<br>
主引用発明に副引用発明を適用する動機付けの有無は、以下の(1)から(4)までの動機付けとなり得る観点を総合考慮して判断される。審査官は、いずれか一つの観点に着目すれば、動機付けがあるといえるか否かを常に判断できるわけではないことに留意しなければならない。<br>
(1) 技術分野の関連性<br>
(2) 課題の共通性<br>
(3) 作用、機能の共通性<br>
(4) 引用発明の内容中の示唆
:::

### (1) 技術分野の関連性

主引用発明に関連する技術分野に、置き換えたり付け加えたりできる技術手段があれば、動機付けの根拠になります。ただし、**この観点だけで決めず、ほかの観点もあわせて考える**のが原則です。

<div class="example">

例1（基準）：電話装置

- 請求項：アドレス帳の宛先を**通信頻度**に応じて並べ替える**電話装置**
- 主引用発明：アドレス帳の宛先を**ユーザが設定した重要度**に応じて並べ替える電話装置
- 副引用発明：アドレス帳の宛先を**通信頻度**に応じて並べ替える**ファクシミリ装置**
- 説明：どちらも「アドレス帳を備えた通信装置」なので技術分野は関連。さらに「通信したい宛先への発信操作を簡単にする」点でも共通なら、課題や作用・機能もあわせて考慮したことになる

</div>

### (2) 課題の共通性

主引用発明と副引用発明の課題が共通していれば、動機付けの根拠になります。**文献に書いていなくても、当業者にとって自明な課題・容易に着想できる課題**が共通する場合も含みます。

<div class="example">

例2（基準）：ペットボトル

- 請求項：表面に**硬質炭素膜**が形成されたペットボトル
- 主引用発明：表面に**酸化ケイ素膜**が形成されたペットボトル（ガスバリア性を高めるため）
- 副引用発明：表面に**硬質炭素膜**が形成された密封容器（ガスバリア性を高めるため）
- 説明：どちらも「ガスバリア性を高める」という課題が共通

</div>

<div class="example">

例3（基準）：調理鋏

- 請求項：握り部に**栓抜き部**が備えられた調理鋏
- 主引用発明：握り部に**殻割部**が備えられた調理鋏
- 副引用発明：握り部に**栓抜き部**が備えられたペティーナイフ
- 説明：調理器具の**多機能化は自明の課題**なので、課題は共通

</div>

::: info 原文（基準 III-2-2 3.1.1(2)）
審査官は、請求項に係る発明とは別の課題を有する引用発明に基づき、主引用発明から出発して請求項に係る発明とは別の思考過程による論理付けを試みることもできる。試行錯誤の結果の発見に基づく発明等、請求項に係る発明の課題が把握できない場合も同様である。
:::

「本願と課題が違うから進歩性あり」とは**限らない**、ということです。

### (3) 作用、機能の共通性

<div class="example">

例4（基準）：印刷機

- 請求項：**膨張部材**を膨張させて洗浄布を接触させ、**ブランケットシリンダ**を洗浄する印刷機
- 主引用発明：**カム機構**を用いて洗浄布を接触させ、ブランケットシリンダを洗浄する印刷機
- 副引用発明：膨張部材を膨張させて洗浄布を接触させ、**凹版シリンダ**を洗浄する印刷機
- 説明：カム機構も膨張部材も「洗浄布をシリンダに接触・離反させる」作用のためのもので、作用が共通

</div>

### (4) 引用発明の内容中の示唆

文献の中に「こうしてもいいよ」という**示唆**があれば、動機付けの**有力な**根拠になります。

<div class="example">

例5（基準）：透明フィルム

- 請求項：EVA共重合体と受酸剤粒子を含み、さらに**架橋剤で架橋**された透明フィルム
- 主引用発明：EVA共重合体と受酸剤粒子を含む透明フィルム（文献に「**太陽電池の構成部品と接触する部材**として用いられる」との言及あり）
- 副引用発明：**太陽電池用封止膜**に用いられ、架橋剤で架橋されたEVA透明フィルム
- 説明：主引用発明の文献の言及は、太陽電池用封止膜の技術を適用することを示唆している

</div>

## 2. 設計変更等

::: info 原文（基準 III-2-2 3.1.2(1)）
請求項に係る発明と主引用発明との相違点について、以下の(i)から(iv)までのいずれか(以下この章において「設計変更等」という。)により、主引用発明から出発して当業者がその相違点に対応する発明特定事項に到達し得ることは、進歩性が否定される方向に働く要素となる。さらに、主引用発明の内容中に、設計変更等についての示唆があることは、進歩性が否定される方向に働く有力な事情となる。<br>
(i) 一定の課題を解決するための公知材料の中からの最適材料の選択(例1)<br>
(ii) 一定の課題を解決するための数値範囲の最適化又は好適化(例2)<br>
(iii) 一定の課題を解決するための均等物による置換(例3)<br>
(iv) 一定の課題を解決するための技術の具体的適用に伴う設計変更や設計的事項の採用(例4及び例5)<br>
これらは、いずれも当業者の通常の創作能力の発揮にすぎないからである。
:::

| 類型 | 審査基準の例 |
|---|---|
| (i) 最適材料の選択 | 球技用ボールの外皮とボールの接着剤を、加圧接着型から周知の**水反応型接着剤**に変える |
| (ii) 数値範囲の最適化 | 硬化前コンクリートで、流動性を悪くする75μm以下の粒子を**1.5質量%以下**に減らす |
| (iii) 均等物による置換 | 浴室乾燥装置の駆動手段を、ブラシ付きDCモータから周知の**ブラシレスDCモータ**に変える |
| (iv) 設計的事項 | 携帯電話をデジタルテレビにつないで表示するとき、テレビの画面サイズ・解像度に合った信号を出す／宿泊施設情報システムで、旅行代理店の慣行を参考に入力項目に「飲食物」、出力に「築年数」を採用する |

::: details 副引用発明を適用するときにも、設計変更等は考慮される
副引用発明をそのまま当てはめただけでは請求項に届かなくても、**当てはめる際に設計変更等をすれば届く**なら、論理付けは成り立ちえます（基準 III-2-2 3.1.1(注1)）。附属書A 進歩性 事例3（レンチキュラーシート）がその例で、引用発明2の「トナー散布」を周知の「転写」に変える設計変更をしつつ適用しています。[事例演習](/practice/cases) で詳しく見ます。
:::

## 3. 先行技術の単なる寄せ集め

::: info 原文（基準 III-2-2 3.1.2(2)）
先行技術の単なる寄せ集めとは、発明特定事項の各々が公知であり、互いに機能的又は作用的に関連していない場合をいう。発明が各事項の単なる寄せ集めである場合は、その発明は当業者の通常の創作能力の発揮の範囲内でなされたものである。
:::

<div class="example">

例6（基準）：公知の昇降手段Aを備えた外壁作業用ゴンドラ装置に、公知の**防風用カバー部材**と、公知の**作業用具収納手段**をそれぞれ付け加える → 単なる寄せ集め

</div>

逆に言えば、組み合わせた構成が**互いに作用しあって新しい効果を生む**なら、単なる寄せ集めではありません。

::: warning 社内判定では
研究員さんのアイデアが「既存技術Aと既存技術Bの組合せ」に見えたら、次の質問をしてみましょう。

- AとBは**同じ分野**？ 課題は**共通**？ 同じ**働き**をしている？ どこかの文献に**組み合わせのヒント**はある？（→ 動機付けの4観点）
- 組み合わせたことで、**AとBが互いに影響しあう**ような効果は出ている？（→ 単なる寄せ集めではない根拠）
- 組み合わせるときに、**普通はやらない工夫**が必要だった？（→ 設計変更等を超える部分）
:::
