# B2 先行技術とは

<p class="lead">「この発明はもう世の中に知られていたか？」を判断するには、そもそも何が「知られていた」ことになるのかを知る必要があります。29条1項の3つの類型を見ていきましょう。</p>

::: tip ざっくり言うと
- 先行技術＝**出願より前に**、日本でも外国でも、①公然知られた ②公然実施をされた ③刊行物に載った／ネットで公衆に利用可能になった 発明
- 「前」かどうかは**時・分・秒**まで比べる（外国なら日本時間に直す）
- 守秘義務がある人の間で共有されただけなら、まだ「公然」ではない
:::

## 条文

::: info 原文（特許法29条1項）
産業上利用することができる発明をした者は、次に掲げる発明を除き、その発明について特許を受けることができる。<br>
一 特許出願前に日本国内又は外国において公然知られた発明<br>
二 特許出願前に日本国内又は外国において公然実施をされた発明<br>
三 特許出願前に日本国内又は外国において、頒布された刊行物に記載された発明又は電気通信回線を通じて公衆に利用可能となつた発明
:::

::: info 原文（基準 III-2-1 1.）
特許制度は発明公開の代償として特許権を付与するものであるから、特許権が付与される発明は新規な発明でなければならない。
:::

## 「前」かどうかは時刻まで

::: info 原文（基準 III-2-3 3.1）
先行技術は、本願の出願時より前に、日本国内又は外国において、3.1.1から3.1.4までのいずれかに該当したものである。本願の出願時より前か否かの判断は、時、分、秒まで考慮してなされる。外国で公知になった場合については、日本時間に換算した時刻で比較してその判断がなされる。
:::

<div class="example">

例（HB 3205）：午前中に日本国内で公然知られた発明について、**その日の午後**に特許出願をした → その発明は「特許出願前に公然知られた発明」です。同じ日でもアウトになりえます。

</div>

## ① 刊行物に記載された発明（29条1項3号）

::: info 原文（基準 III-2-3 3.1.1）
「頒布された刊行物に記載された発明」とは、不特定の者が見得る状態に置かれた(注1)刊行物(注2)に記載された発明をいう。<br>
(注1) 現実に誰かが見たという事実を必要としない。<br>
(注2) 「刊行物」とは、公衆に対し、頒布により公開することを目的として複製された文書、図面その他これに類する情報伝達媒体をいう。
:::

**実際に誰かが読んだかどうかは関係ない**、というのがポイントです。図書館に置かれた時点、配布された時点で「見得る状態」になります。

### 発行日がはっきりしないときは？

刊行物に書かれている発行時期によって、次のように**推定**します（基準 III-2-3 3.1.1(2)）。

| 刊行物の記載 | 推定される頒布時期 |
|---|---|
| 発行の**年**だけ | その年の**末日**の終了時 |
| 発行の**年月**まで | その年月の**末日**の終了時 |
| 発行の**年月日**まで | その年月日の終了時 |
| 発行時期の記載なし・外国刊行物で国内受入れ時期がわかる | 受入れ時期から、通常かかる期間をさかのぼった時期 |
| 書評・抜粋・カタログなどを載せた別の刊行物がある | その別の刊行物の発行時期から推定 |
| 重版・再版で初版の発行時期が書いてある | 初版の発行時期 |

「年だけ」のときは**その年の最後の日**と推定されるので、出願が同じ年だと「出願より前」とは言いにくくなります。

### 出願日と発行日が同じ日のとき

::: info 原文（基準 III-2-3 3.1.1(2)b）
特許出願の日と刊行物の発行日とが同日の場合は、審査官は、刊行物の発行の時が特許出願の時よりも前であることが明らかな場合のほかは、頒布時期を特許出願前であると取り扱わない。
:::

## ② 公然知られた発明（29条1項1号）

::: info 原文（基準 III-2-3 3.1.3）
「公然知られた発明」とは、不特定の者に秘密でないものとしてその内容が知られた発明をいう(注)。<br>
(注) 守秘義務を負う者から秘密でないものとして他の者に知られた発明は、「公然知られた発明」である。このことと、発明者又は出願人の秘密にする意思の有無とは関係しない。<br>
学会誌等の原稿は、一般に、その原稿が受け付けられても不特定の者に知られる状態に置かれるものではない。したがって、その原稿の内容が公表されるまでは、その原稿に記載された発明は、「公然知られた発明」とはならない。
:::

講演会や説明会で説明されたものが典型です。

## ③ 公然実施をされた発明（29条1項2号）

::: info 原文（基準 III-2-3 3.1.4）
「公然実施をされた発明」とは、その内容が公然知られる状況又は公然知られるおそれのある状況で実施をされた発明をいう(注)。
:::

<div class="example">

例（HB 3214）：工場見学

- 不特定の人に製造の様子を見学させ、**見れば当業者が発明の内容を容易に知ることができる** → 公然実施
- 装置の外からは一部がわからないけれど、見学者が<strong>中を見せてもらったり、説明を受けたりできる（工場が拒否しない）</strong> → 「公然知られるおそれのある状況」で公然実施

</div>

::: warning 社内判定では
研究員さんへのヒアリングで、必ず確認したいこと：

- **学会発表・論文投稿の予定や実績**（投稿しただけならまだ公知ではないが、公表されたらアウト → [C3 新規性喪失の例外](/related/c3-grace-period)）
- **展示会・顧客へのサンプル提供・工場見学**（守秘義務契約があるか？）
- **共同研究先への開示**（NDA を結んでいるか？）

守秘義務を負う人が秘密でないものとして第三者に話してしまうと、その時点で「公然知られた」ことになります。
:::
