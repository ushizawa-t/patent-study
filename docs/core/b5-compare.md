# B5 対比

<p class="lead">本願の発明と引用発明がそろったら、いよいよ比べます。ここでやることはシンプルで、「一致点」と「相違点」をきちんと書き出すことです。</p>

::: tip ざっくり言うと
- 請求項の**発明特定事項**と、引用発明の**引用発明特定事項**を、項目ごとに並べて比べる
- 結果を「一致点」「相違点」として整理する
- **独立した2つ以上の引用発明を合体させて**対比してはいけない（それは進歩性の検討でやること）
- 選択肢がある請求項は、選択肢のどれか1つを取り出して比べてよい
:::

## 対比の基本

::: info 原文（基準 III-2-3 4.1）
審査官は、認定した請求項に係る発明と、認定した引用発明とを対比する。請求項に係る発明と引用発明との対比は、請求項に係る発明の発明特定事項と、引用発明を文言で表現する場合に必要と認められる事項(以下この章において「引用発明特定事項」という。)との一致点及び相違点を認定してなされる。審査官は、独立した二以上の引用発明を組み合わせて請求項に係る発明と対比してはならない。
:::

## 対比表をつくろう

実務では、次のような<strong>対比表（クレームチャート）</strong>を作ります。

| 本願の発明特定事項 | 引用発明（文献1） | 判断 |
|---|---|---|
| A：プリンタ本体の動作状態を通常／省電力に設定する制御部 | 制御部あり（段落【0012】） | 一致 |
| B：要求信号が所定時間連続して維持されたときだけ有効と判断 | 記載なし | **相違** |

コツは次のとおりです。

1. 請求項を**意味のまとまりごと**に分ける（分説）
2. 文献のどこに書いてあるか（段落番号・図番号）を必ずメモする
3. 「なんとなく同じ」ではなく、**言葉の意味が同じか**を確認する
4. 相違点は、あとで進歩性を検討しやすいよう**具体的に**書く

[演習：対比表ワーク](/practice/compare) で実際にやってみましょう。

## 選択肢がある請求項

::: info 原文（基準 III-2-3 4.1.1）
審査官は、選択肢(注1)中のいずれか一の選択肢のみを、その選択肢に係る発明特定事項と仮定したときの請求項に係る発明と、引用発明とを対比することができる(注2)。
:::

選択肢には2種類あります（HB 3216）。

| 種類 | 意味 | 例 |
|---|---|---|
| 形式上の選択肢 | 請求項の記載から**一見して選択肢**とわかるもの | マーカッシュ形式、「請求項1又は2に記載の…」 |
| 事実上の選択肢 | 包括的な表現で、**実質的に有限個**の具体的な事項を含めようとしたもの | 「C1〜C10のアルキル基」 |

::: danger よくある間違い
「熱可塑性樹脂」のような言葉は、原則として事実上の選択肢**ではありません**。ポリエチレンやポリプロピレンなど不特定多数のものを「熱可塑性」という共通の性質でまとめた**上位概念**です（HB 3216）。
:::

::: details 選択肢の1つで新規性がなければ、請求項全体が新規性なし？
はい。選択肢の1つを仮定した発明が引用発明と相違点なしなら、その請求項に係る発明は新規性を有しないと判断されます（基準 III-2-3 5.1.1）。逆に「新規性・進歩性あり」と判断するには、**全部の選択肢**について検討する必要があります（4.1.1 注2）。
:::

## ほかの対比の手法

| 手法 | どんなとき便利？ |
|---|---|
| **請求項の下位概念**と引用発明を対比する（4.2） | 機能・特性で特定した請求項、数値範囲で限定した請求項の新規性を判断するとき。実施例以外の下位概念でもOK |
| 対比のときに**出願時の技術常識**を参酌し、文献の記載を解釈しながら一致点・相違点を認定する（4.3） | 文献の言葉づかいが本願と違うとき。ただし、ほかの手法と結論が変わってはいけない |

::: warning 社内判定では
研究員さんに結果を説明するときも、対比表はとても役に立ちます。「この部分は文献1と同じ」「ここが違うので、ここを強みにできる」と**見える化**すると、どこを膨らませて明細書を書けばいいかが一緒に考えやすくなります。
:::
