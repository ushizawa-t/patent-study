# B6 新規性の判断

<p class="lead">対比ができたら、新規性の判断はとてもシンプルです。相違点があるか、ないか。それだけです。</p>

::: tip ざっくり言うと
- 相違点が**ない** → 新規性なし
- 相違点が**ある** → 新規性あり（→ 次は進歩性を検討）
- 判断は**請求項ごと**に行う
:::

## 判断のルール

::: info 原文（基準 III-2-1 2.）
新規性の判断の対象となる発明は、請求項に係る発明である。<br>
審査官は、請求項に係る発明が新規性を有しているか否かを、請求項に係る発明と、新規性及び進歩性の判断のために引用する先行技術(引用発明)とを対比した結果、請求項に係る発明と引用発明との間に相違点があるか否かにより判断する。相違点がある場合は、審査官は、請求項に係る発明が新規性を有していると判断する。相違点がない場合は、審査官は、請求項に係る発明が新規性を有していないと判断する。<br>
審査官は、特許請求の範囲に二以上の請求項がある場合は、請求項ごとに、新規性の有無を判断する。
:::

## 「新規性なし」と「進歩性なし」が両方言える6つのパターン

ハンドブックには、新規性がないと判断されると同時に、進歩性もないと判断されうる例がまとめられています（HB 3201）。新規性の典型パターンの整理にもぴったりです。

| # | パターン | 新規性なしの理由 | 進歩性もない理由 |
|---|---|---|---|
| (i) | 請求項に選択肢がある | ある選択肢で見ると引用発明と同じ | 別の選択肢で見ると容易に想到できる |
| (ii) | 引用文献に実施例が複数ある | ある実施例と同じ | 別の実施例から容易に想到できる |
| (iii) | **請求項が上位概念、引用発明が下位概念** | 上位概念は下位概念を包含する | 下位概念から上位概念にするのは容易 |
| (iv) | **請求項が数値範囲、引用発明がその範囲内の特定の値** | 範囲がその値を包含する | 値を範囲内の他の値に変えるのが容易なら進歩性なし |
| (v) | **引用発明が、請求項の構成にさらに構成を付加したもの** | 請求項は引用発明を包含する | 付加された構成を切り離すのが容易なら進歩性なし |
| (vi) | 請求項が多義的に読める | ある解釈では新規性なし | 別の解釈では進歩性なし |

<div class="example">

例（iii）：請求項は「弾性体」、引用文献には「バネ」だけ

- 「弾性体」はバネを含むので、**新規性なし**
- バネでなくても他の弾性体でよいことは当業者にとって容易なので、**進歩性もなし**

</div>

<div class="example">

例（v）：請求項は「特定の第一関節を備えるロボット用アーム」、引用発明は「特定の第一関節**及び特定の第二関節**を備えるロボット用アーム」

- 請求項の発明は引用発明を包含するので、**新規性なし**
- 「第二関節を切り離して、第一関節だけの発明として考える」ことが容易なら、**進歩性もなし**

</div>

::: danger よくある間違い
「引用発明には、本願にない第二関節もついている。だから違う発明だ！」——これは逆です。請求項に書いていない構成が引用発明に**余分にある**ことは、相違点になりません。請求項の構成が**全部**引用発明にあれば、新規性はありません。
:::

## 拒絶理由通知とその後

審査官が「新規性がない」との心証を得ると、29条1項各号に該当する旨の拒絶理由が通知されます。出願人は補正や意見書・実験成績証明書で反論でき、審査官がその心証を得られない状態になれば拒絶理由は解消します（基準 III-2-3 5.2）。

::: warning 社内判定では
新規性で一番多いのは、パターン(iii)(iv)(v)のような「**広く書きすぎ**」です。研究員さんの発明をそのまま上位概念で書くと、思わぬ文献に包含されてしまうことがあります。

- 文献に何が開示されているかを確認したうえで
- **文献と重ならない範囲**まで請求項を絞れるか（下位概念・数値範囲・追加の構成）
- そのときに**明細書のサポート**（実施例・データ）があるか

を検討しましょう。
:::
