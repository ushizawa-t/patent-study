# B11 特別な表現を含むクレーム

<p class="lead">請求項には、機能で特定したり、用途を書いたり、製造方法で特定したり、いろいろな書き方があります。書き方によって「どう読むか」が変わるので、パターンごとに押さえましょう。</p>

::: tip ざっくり言うと
| 書き方 | 基本の読み方 |
|---|---|
| 機能・特性で特定（「熱を遮断する層」） | その機能・特性を持つ**全ての物** |
| 用途限定（「クレーン用フック」） | その用途に**特に適した構造**を意味するか？ 用途発明か？ |
| 他のサブコンビネーションで特定 | その記載が**本体の構造・機能を特定しているか** |
| 製造方法で特定（PBP） | 最終的にできた**物そのもの** |
| 数値限定 | 普通に認定。相違点が数値だけなら原則**進歩性なし**（顕著な効果があれば別） |
| 選択発明 | 上位概念から選んだ下位概念。**顕著な効果**があれば進歩性あり |
:::

## 1. 機能・特性で物を特定する場合

::: info 原文（基準 III-2-4 2.1）
請求項中に作用、機能、性質又は特性(以下この項(2.)において「機能、特性等」という。)を用いて物を特定しようとする記載がある場合は、審査官は、原則として、その記載を、そのような機能、特性等を有する全ての物を意味していると解釈する。例えば、「熱を遮断する層を備えた壁材」について、審査官は「断熱という作用又は機能を有する層」という「物」を備えた壁材と認定する(注)。
:::

### その物が「もともと持っている」機能の場合

<div class="example">

例（基準）：「高周波数信号をカットし、低周波数信号を通過させるRC積分回路」

- 高周波をカットし低周波を通すのは、RC積分回路が**もともと持っている機能**
- だからこの記載は物を特定するのに役立っておらず、一般的な「RC積分回路」と同じ
- → 一般的なRC積分回路が公知なら、**新規性なし**
- ただし「・・Hz以上をカットし、・・Hz以下を通過させる」と**具体的な周波数特性**を書けば、特定のRC積分回路として認定される

</div>

同様に、「抗癌性を有する化合物X」は、抗癌性が化合物Xの固有の性質なら「化合物X」そのものと認定されます。

### 対比が難しいときは「一応の合理的な疑い」

機能・特性の記載のせいで引用発明と**厳密な対比ができない**場合は、新規性・進歩性が否定されるとの**一応の合理的な疑い**を抱いたときに限り、その疑いを説明したうえで拒絶理由が通知されます（2.2.2）。附属書A 新規性 事例4〜16 がこの類型の事例です。

## 2. 用途限定がある場合

### まず：その用途に特に適した構造を意味するか？

<div class="example">

例（基準）：「〜の形状を有する**クレーン用**フック」

- 「クレーン用」が、クレーンに使うのに特に適した大きさ・強さの構造を意味すると解釈されるなら、同じ形状の「釣り用フック（釣り針）」とは**構造が違う**
- → 釣り針が公知でも、**新規性あり**

</div>

### 次に：用途発明か？

::: info 原文（基準 III-2-4 3.1.2）
用途発明とは、(i)ある物の未知の属性を発見し、(ii)この属性により、その物が新たな用途への使用に適することを見いだしたことに基づく発明をいう。以下に示す用途発明の考え方は、一般に、物の構造又は名称からその物をどのように使用するかを理解することが比較的困難な技術分野(例：化学物質を含む組成物の用途の技術分野)において適用される。
:::

<div class="example">

例（基準）：「成分Aを有効成分とする**二日酔い防止用**食品組成物」

- 成分Aを含む食品組成物は公知
- でも、成分Aが**アルコールの代謝を促進する**という**未知の属性**を発見し、それにより**新たな用途**を見いだしたなら、用途発明
- → 物自体が公知でも、**新規性あり**（ただし既知の属性から容易に想到できれば進歩性なし）

</div>

<div class="example">

逆の例（基準）：「成分Aを有効成分とする**肌のシワ防止用**化粧料」 vs 公知の「成分Aを有効成分とする**肌の保湿用**化粧料」

- シワ防止の属性は未知だったとしても、保湿化粧料がシワ防止にも使われることが技術常識なら、両者の**用途を区別できない**
- → 用途限定は特定の意味を持たず、**新規性なし**

</div>

### 用途限定の考え方が使われない場合

- **化合物・微生物・動物・植物**：「殺虫用の化合物Z」は、用途限定のない「化合物Z」そのもの（有用性を示しているだけ）。ただし「化合物Zを主成分とする**殺虫剤**」なら別
- **機械・器具・物品・装置**：通常、用途発明の考え方は使われない（物と用途が一体だから）

## 3. 他のサブコンビネーションで特定する場合

サブコンビネーション＝組み合わせ全体（コンビネーション）を構成する各装置・各工程のこと。たとえば「サーバ＋クライアント」のシステムに対する「クライアント装置」です。

::: info 原文（基準 III-2-4 4.1）
審査官は、請求項に係る発明の認定の際に、請求項中に記載された「他のサブコンビネーション」に関する事項についても必ず検討対象とし、記載がないものとして扱ってはならない。
:::

| 他のサブコンビネーションの記載が… | 認定・判断 | 審査基準の例 |
|---|---|---|
| 本体の**構造・機能を特定している** | その構造・機能を持つものとして認定。公知でなければ新規性あり | 「検索サーバが**暗号化方式A**で送る」→ クライアントは方式Aに対応した復号手段を持つ |
| 相手方**だけ**を特定し、本体を何も特定していない | 特定の意味なし。他に相違点がなければ新規性なし | 「検索サーバが検索頻度に基づいて検索手法を変更する」クライアント装置／「防犯ブザーがキーホルダーに付いている」キー |

::: danger よくある間違い
「相手方の話だから関係ない」と**決めつけない**こと。基準も、サブコンビネーションと他のサブコンビネーションが異なる物であることだけに着目して、特定の意味がないと誤解しないよう注意しています（4.1.2）。暗号化方式の例のように、相手方の記載が本体の構造を決めていることもあります。
:::

## 4. 製造方法で物を特定する場合（プロダクト・バイ・プロセス）

::: info 原文（基準 III-2-4 5.1）
請求項中に製造方法によって生産物を特定しようとする記載がある場合は、審査官は、その記載を、最終的に得られた生産物自体を意味しているものと解釈する。したがって、出願人自らの意思で、「専らAの方法により製造されたZ」のように、特定の方法によって製造された物のみに限定しようとしていることが明白な場合であっても、審査官は、生産物自体(Z)を意味しているものと解釈し、請求項に係る発明を認定する。
:::

<div class="example">

例（基準）：「製造方法P（工程p1, p2 … pn）により生産されるタンパク質」

- 製造方法Pで作ったタンパク質が、別の方法Qで作られる公知のタンパク質Zと**同じ物**なら
- 製造方法Pが新しいかどうかにかかわらず、**新規性なし**

</div>

::: warning 社内判定では
「新しい作り方を見つけた」発明は、**物の請求項**にすると、できた物が同じなら新規性がありません。**製造方法の請求項**で権利化を考えましょう。
:::

## 5. 数値限定

::: info 原文（基準 III-2-4 6.2）
請求項に数値限定を用いて発明を特定しようとする記載がある場合において、主引用発明との相違点がその数値限定のみにあるときは、通常、その請求項に係る発明は進歩性を有していない。実験的に数値範囲を最適化又は好適化することは、通常、当業者の通常の創作能力の発揮といえるからである。<br>
しかし、請求項に係る発明の引用発明と比較した効果が以下の(i)から(iii)までの全てを満たす場合は、審査官は、そのような数値限定の発明が進歩性を有していると判断する。<br>
(i) その効果が限定された数値の範囲内において奏され、引用発明の示された証拠に開示されていない有利なものであること。<br>
(ii) その効果が引用発明が有する効果とは異質なもの、又は同質であるが際だって優れたものであること(すなわち、有利な効果が顕著性を有していること。)。<br>
(iii) その効果が出願時の技術水準から当業者が予測できたものでないこと。<br>
なお、有利な効果が顕著性を有しているといえるためには、数値範囲内の全ての部分で顕著性があるといえなければならない。<br>
また、請求項に係る発明と主引用発明との相違が数値限定の有無のみで、課題が共通する場合は、いわゆる数値限定の臨界的意義として、有利な効果の顕著性が認められるためには、その数値限定の内と外のそれぞれの効果について、量的に顕著な差異がなければならない。他方、両者の相違が数値限定の有無のみで、課題が異なり、有利な効果が異質である場合には、数値限定に臨界的意義があることは求められない。
:::

| 相違点が数値限定だけのとき | 必要なこと |
|---|---|
| 課題が**共通** | **臨界的意義**：範囲の内と外で、効果に**量的に顕著な差**がある |
| 課題が**異なり**、効果が**異質** | 臨界的意義までは不要 |
| どちらでも | 範囲内の**全部**で顕著な効果があること |

::: warning 社内判定では
数値限定の発明では、**範囲の内側と外側のデータ**（特に境界付近）がないと勝負になりません。研究員さんに「範囲の外ではどうなりますか？」と必ず聞いて、比較例のデータを明細書に入れてもらいましょう。
:::

## 6. 選択発明

::: info 原文（基準 III-2-4 7.1）
選択発明とは、物の構造に基づく効果の予測が困難な技術分野に属する発明であって、以下の(i)又は(ii)に該当するものをいう。<br>
(i) 刊行物等において上位概念で表現された発明(a)から選択された、その上位概念に包含される下位概念で表現された発明(b)であって、刊行物等において上位概念で表現された発明(a)により新規性が否定されないもの<br>
(ii) 刊行物等において選択肢(注)で表現された発明(a)から選択された、その選択肢の一部を発明特定事項と仮定したときの発明(b)であって、刊行物等において選択肢で表現された発明(a)により新規性が否定されないもの
:::

進歩性は、効果が (i) 刊行物等に記載されていない有利なもので、(ii) 上位概念・選択肢の発明の効果と異質、または同質でも際立って優れていて、(iii) 当業者が予測できなかった——の**全部**を満たせば認められます（7.2）。

<div class="example">

例（基準）：ある一般式の化合物が殺虫性を持つことは知られていた。その一般式に含まれる、殺虫性について具体的に公知でない特定の化合物について、**人への毒性が他の化合物より顕著に少ない**ことを見いだし、殺虫剤の有効成分として選択した。予測可能とする証拠もない → **選択発明として進歩性あり**

</div>
