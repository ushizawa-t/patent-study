# B4 引用発明の認定

<p class="lead">比べるもう片方、先行技術の側（引用発明）をどう読むかです。ここで読み間違えると、判定全体がずれてしまいます。</p>

::: tip ざっくり言うと
- 引用発明は、文献に「**記載されている事項**」と「**記載されているに等しい事項**」（技術常識から当業者が導き出せること）から認定する
- 物なら「作れる」、方法なら「使える」ことが明らかでないものは引用発明にできない
- 上位概念しか書いていない文献から、下位概念の発明は原則として認定できない
- 本願を読んだあとの「**後知恵**」で文献を曲げて読まない
:::

## 刊行物に「記載された発明」とは

::: info 原文（基準 III-2-3 3.1.1(1)a）
「刊行物に記載された発明」とは、刊行物に記載されている事項及び刊行物に記載されているに等しい事項から把握される発明をいう。審査官は、これらの事項から把握される発明を、刊行物に記載された発明として認定する。刊行物に記載されているに等しい事項とは、刊行物に記載されている事項から本願の出願時における技術常識を参酌することにより当業者が導き出せる事項をいう。
:::

文字どおり書いてあることだけでなく、その分野の人なら当然読み取れることも含めて読む、ということです。

## 作れない・使えないものは引用できない

::: info 原文（基準 III-2-3 3.1.1(1)b）
審査官は、刊行物に記載されている事項及び記載されているに等しい事項から当業者が把握することができる発明であっても、以下の(i)又は(ii)の場合は、その刊行物に記載されたその発明を「引用発明」とすることができない。<br>
(i) 物の発明については、刊行物の記載及び本願の出願時の技術常識に基づいて、当業者がその物を作れることが明らかでない場合<br>
(ii) 方法の発明については、刊行物の記載及び本願の出願時の技術常識に基づいて、当業者がその方法を使用できることが明らかでない場合
:::

<div class="example">

例（附属書A 新規性 事例1「レンズ」）

- 本願：厚さ **1μm〜2μm** の物質B中間層を均一に形成したレンズ。新しい干渉計を使えば薄い層でも測れることを見つけた
- 引用文献：「7μm以下の中間層を均一に設ける」「例えば1μm程度でもよい」と書いてある
- でも、出願時の技術常識では「5μm以下の中間層は厚さを測定できない」ので、1μm〜2μmに制御して作る方法は当業者にはわからない
- → 引用文献のうち中間層5μm以下のものは「引用発明」にできず、**本願は新規性あり**

「数値が書いてある＝開示されている」とは限らない、という好例です。

</div>

## 上位概念・下位概念の扱い

| 文献の書き方 | 引用発明として認定できるもの |
|---|---|
| **上位概念**で書いてある（例：「金属」） | 下位概念（例：「銅」）の発明は**原則として認定できない**。ただし技術常識から導き出せる場合は可 |
| **下位概念**で書いてある（例：「銅」） | 上位概念（例：「金属」）の発明は認定できる |

::: info 原文（基準 III-2-3 3.2(1)(注2)）
概念上、下位概念が上位概念に含まれる、又は上位概念の用語から下位概念の用語を列挙することができることのみでは、下位概念で表現された発明が導き出される(記載されている)とはしない。
:::

「金属と書いてあれば銅も含まれるでしょ」は通用しない、ということです。この考え方は [B11 選択発明](/core/b11-special-claims) にもつながります。

### マーカッシュ形式の文献

文献に「R は、メチル基、エチル基、…のいずれか」のような選択肢の形で書かれている場合は、その中の**1つだけ**を選んだ発明を当業者が把握できるかを検討します（HB 3206）。

## 後知恵に注意

::: info 原文（基準 III-2-3 3.3）
審査官は、請求項に係る発明の知識を得た上で先行技術を示す証拠の内容を理解すると、本願の明細書、特許請求の範囲又は図面の文脈に沿ってその内容を曲解するという、後知恵に陥ることがある点に留意しなければならない。引用発明は、引用発明が示されている証拠に依拠して(刊行物であれば、その刊行物の文脈に沿って)理解されなければならない。
:::

さらにハンドブックでは、次の2点にも注意するよう書かれています（HB 3215）。

1. 文献の**一部の記載だけ**から、合理的な根拠なく引用発明を認定しない
2. 構成だけでなく、**解決すべき課題・技術分野**などの観点も考えて読む

::: danger よくある間違い
本願を読んだ直後に文献を読むと、「この部品は本願の○○と同じ役割だ！」と都合よく読んでしまいがちです。**文献は文献の文脈で読む**。文献の中でその部品が何のために使われているかを確認しましょう。
:::

::: warning 社内判定では
研究員さんは「この論文、うちのアイデアと同じことが書いてある…」と落ち込んでいることがあります。でも、よく読むと

- 上位概念でしか書かれていない
- 作り方がわからない（実施可能でない）
- 別の目的で使われていて、文脈が違う

ということもよくあります。**文献に本当に「記載された発明」は何か**を冷静に確認するのが知財部の役目です。
:::
