# B1 請求項に係る発明の認定

<p class="lead">新規性・進歩性の判断は、「何と何を比べるか」をはっきりさせるところから始まります。まずは比べる片方、<strong>請求項に係る発明</strong>を正しくつかむ練習です。</p>

::: tip ざっくり言うと
- 判断の対象は「**請求項に書かれた発明**」。明細書に書いてあっても、請求項に書いていないことは考えない
- 逆に、請求項に書いてあることは**必ず全部**考える（無視しない）
- 用語の意味は、明細書・図面と出願時の技術常識をふまえて解釈する
:::

## 全体の流れの中での位置づけ

新規性・進歩性の審査は、次の4ステップで進みます。このページは①です。

```
① 請求項に係る発明の認定   ← いまここ
② 引用発明の認定           （B2〜B4）
③ 対比（一致点・相違点）    （B5）
④ 新規性・進歩性の判断      （B6〜B11）
```

::: info 原文（基準 III-2-3 1.）
審査官は、新規性及び進歩性の判断をするに当たり、請求項に係る発明の認定と、引用発明の認定とを行い、次いで、両者の対比を行う。対比の結果、相違点がなければ、審査官は、請求項に係る発明が新規性を有していないと判断し(第1節)、相違点がある場合には、進歩性の判断を行う(第2節)。
:::

## 基本ルール：請求項の記載がスタート地点

::: info 原文（基準 III-2-3 2.）
審査官は、請求項に係る発明を、請求項の記載に基づいて認定する。この認定において、審査官は、明細書及び図面の記載並びに出願時の技術常識を考慮して請求項に記載されている用語の意義を解釈する。<br>
審査官は、請求項の記載に基づき認定した発明と明細書又は図面に記載された発明とが対応しないことがあっても、請求項の記載を無視して明細書又は図面の記載のみから請求項に係る発明を認定し、それを審査の対象とはしない。審査官は、明細書又は図面に記載があっても、請求項には記載されていない事項は、請求項には記載がないものとして請求項に係る発明の認定を行う。反対に、審査官は、請求項に記載されている事項については必ず考慮の対象とし、記載がないものとして扱ってはならない。
:::

つまり、こういうことです。

| | 請求項に書いてある | 請求項に書いていない |
|---|---|---|
| 明細書に書いてある | 考える ✓ | **考えない**（明細書にしかない限定を勝手に足さない） |
| 明細書に書いていない | **必ず考える**（無視しない） | — |

::: danger よくある間違い
「実施例では○○になっているから、この発明は○○のことだろう」と、**実施例の限定を請求項に読み込んでしまう**ミス。請求項が広く書かれていれば、発明も広いものとして扱います。広い分、先行技術にも当たりやすくなる、ということです。
:::

## 記載のはっきり具合で3パターン

| パターン | どう扱う？ |
|---|---|
| 請求項の記載が明確 | 書いてあるとおりに認定。用語は**通常の意味**で解釈（ただし明細書に定義・説明があればそれを考慮） |
| 一見わかりにくいが、明細書等を見ると明確になる | 明細書・図面・技術常識を考慮して用語を解釈する |
| 明細書等を見ても明確にならない | 発明の認定を行わない（明確性要件の問題 → [C6](/related/c6-description)） |

::: info 原文（基準 III-2-3 2.1）
この場合は、審査官は、請求項の記載どおりに請求項に係る発明を認定する。また、審査官は、請求項の用語の意味を、その用語が有する通常の意味と解釈する。<br>
ただし、請求項に記載されている用語の意味内容が明細書又は図面において定義又は説明されている場合は、審査官は、その定義又は説明を考慮して、その用語を解釈する。なお、請求項の用語の概念に含まれる下位概念を単に例示した記載が発明の詳細な説明又は図面中にあるだけでは、ここでいう定義又は説明には該当しない。
:::

<div class="example">

例：「弾性体」と書いてある請求項

- 明細書の実施例には「バネ」しか出てこない
- でも、明細書に「本発明でいう弾性体とはバネをいう」という**定義**がない限り、「弾性体」はゴムなども含む広い意味で解釈します
- 「実施例にバネがある」は、下位概念を**例示しただけ**なので、定義にはなりません

</div>

## リパーゼ事件判決（最高裁）

この考え方のもとになっているのが、いわゆる「リパーゼ事件」の最高裁判決です。判定の世界では超有名なので、名前だけでも覚えておきましょう。

::: info 原文（HB 3204 より　最二小判平成3年3月8日「トリグリセリドの測定法」）
特許法二九条一項及び二項所定の特許要件、すなわち、特許出願に係る発明の新規性及び進歩性について審理するに当たっては、この発明を同条一項各号所定の発明と対比する前提として、特許出願に係る発明の要旨が認定されなければならないところ、この要旨認定は、特段の事情のない限り、願書に添付した明細書の特許請求の範囲の記載に基づいてされるべきである。特許請求の範囲の記載の技術的意義が一義的に明確に理解することができないとか、あるいは、一見してその記載が誤記であることが明細書の発明の詳細な説明の記載に照らして明らかであるなどの特段の事情がある場合に限って、明細書の発明の詳細な説明の記載を参酌することが許されるにすぎない。
:::

ポイントは「明細書を**読むな**」ではなく、「技術内容を理解するために明細書は読む。でも、**請求項にない構成要件を明細書から付け加えてはいけない**」ということです（HB 3204 に引用されている判例解説の趣旨）。

## 選択肢のある請求項

「A又はB」のような書き方（形式上の選択肢）や、「C1〜C10のアルキル基」のように実質的に有限個の具体例をまとめた書き方（事実上の選択肢）がある場合、**選択肢のどれか1つ**に着目して対比・判断することができます。詳しくは [B5 対比](/core/b5-compare) で扱います。

::: warning 社内判定では
社内判定では、まだ請求項がないことがほとんどです。研究員さんの提案を、次のように**請求項っぽく分解**してみましょう。

1. 発明の**課題**（何に困っていたか）を一文で書く
2. 課題を解決する**手段**を、構成要素ごとに A、B、C … と分ける（「分説」といいます）
3. それぞれを、どこまで<strong>広い言葉（上位概念）</strong>にできるか考える（例：「バネ」→「弾性体」）
4. 広い版と狭い版の両方で、先行技術と比べる

広く書けばそれだけ先行技術に当たりやすく、狭く書けば通りやすいが権利は小さくなります。このバランスを考えるのが判定の腕の見せどころです。
:::
