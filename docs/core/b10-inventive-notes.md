# B10 進歩性④ 注意点

<p class="lead">進歩性の判断で、審査基準が「ここは気をつけて」と挙げているポイントのまとめです。判定の最後に見直すチェックリストとして使ってください。</p>

::: tip ざっくり言うと
1. 後知恵に陥らない
2. 主引用発明は技術分野・課題が近いものを選ぶ
3. 周知技術でも、阻害要因などの検討は省略しない
4. 明細書で「従来技術」と認めているものは引用発明にできる
5. 物が進歩性ありなら、その製法・用途も原則進歩性あり
6. 商業的成功などは「二次的な指標」
7. 周知技術は、原則として証拠を示す
:::

## 1. 後知恵に注意

::: info 原文（基準 III-2-2 3.3(1)）
請求項に係る発明の知識を得た上で、進歩性の判断をするために、以下の(i)又は(ii)のような後知恵に陥ることがないように、審査官は留意しなければならない。<br>
(i) 当業者が請求項に係る発明に容易に想到できたように見えてしまうこと。<br>
(ii) 引用発明の認定の際に、請求項に係る発明に引きずられてしまうこと(「第3節 新規性・進歩性の審査の進め方」の3.3参照)。
:::

答えを知ってから問題を見ると、どんな問題も簡単に見えます。「**この発明を知らない当業者が、出願時にどうしたか**」を常に意識しましょう。

## 2. 主引用発明の選択と、課題が新規な場合

::: info 原文（基準 III-2-2 3.3(2)）
また、請求項に係る発明の解決すべき課題が新規であり、当業者が通常は着想しないようなものである場合は、請求項に係る発明と主引用発明とは、解決すべき課題が大きく異なることが通常である。したがって、請求項に係る発明の課題が新規であり、当業者が通常は着想しないようなものであることは、進歩性が肯定される方向に働く一事情になり得る。
:::

「誰も困っていると気づいていなかった課題」を見つけたこと自体が、進歩性を後押しすることがあります。

## 3. 周知技術でも検討は省略しない

::: info 原文（基準 III-2-2 3.3(3)）
審査官は、論理付けのために引用発明として用いたり、設計変更等の根拠として用いたりする周知技術について、周知技術であるという理由だけで、論理付けができるか否かの検討(その周知技術の適用に阻害要因がないか等の検討)を省略してはならない。
:::

附属書A 進歩性 事例1・2 は、まさに「周知技術だけど、当てはめるには阻害要因がある」例でした。

## 4. 明細書で認めた従来技術

::: info 原文（基準 III-2-2 3.3(4)）
審査官は、本願の明細書中に本願出願前の従来技術として記載されている技術について、出願人がその明細書の中でその従来技術の公知性を認めている場合は、出願当時の技術水準を構成するものとして、これを引用発明とすることができる。
:::

::: warning 社内判定では
明細書の「背景技術」に**社内でしか知られていない技術**を「従来技術」として書いてしまうと、それが公知だと認めたことになり、引用発明にされてしまうおそれがあります。背景技術に何を書くかは慎重に。
:::

## 5. 物 → 製造方法・用途

::: info 原文（基準 III-2-2 3.3(5)）
物自体の発明が進歩性を有している場合には、その物の製造方法及びその物の用途の発明は、原則として、進歩性を有している(注2)。<br>
(注2) 例外としては、物自体の発明が用途発明(「第4節 特定の表現を有する請求項等についての取扱い」の3.1.2参照)である場合における、その物の製造方法が挙げられる。
:::

## 6. 商業的成功は二次的な指標

::: info 原文（基準 III-2-2 3.3(6)）
審査官は、商業的成功、長い間その実現が望まれていたこと等の事情を、進歩性が肯定される方向に働く事情があることを推認するのに役立つ二次的な指標として参酌することができる。ただし、審査官は、出願人の主張、立証により、この事情が請求項に係る発明の技術的特徴に基づくものであり、販売技術、宣伝等、それ以外の原因に基づくものではないとの心証を得た場合に限って、この参酌をすることができる。
:::

「売れた」理由が**技術的特徴のおかげ**であることを示す必要があります。宣伝がうまかったから売れた、では足りません。

## 7. 周知技術・慣用技術には証拠を

::: info 原文（基準 III-2-3 5.3(3)）
審査官は、拒絶理由通知又は拒絶査定において、論理付けに周知技術又は慣用技術を用いる場合は、例示するまでもないときを除いて、周知技術又は慣用技術であることを根拠付ける証拠を示す。このことは、周知技術又は慣用技術が引用発明として用いられるのか、設計変更等の根拠として用いられるのか、又は当業者の知識(注1)若しくは能力(注2)の認定の基礎として用いられるのかにかかわらない。
:::

## 拒絶理由通知の書かれ方

進歩性がないとの心証を得た場合、審査官は、**相違点を明確に示したうえで、主引用発明から出発して容易に到達する論理付けを記載**します（基準 III-2-3 5.3(1)）。

また、補正や意見書のあと、**新たな証拠を追加しなければ論理付けできない**場合は、通知した拒絶理由は維持されないと判断されます（ただし、すでに示した論理付けに不備はなく、それを補うために周知技術・慣用技術の証拠を追加する場合は除く）（5.3(2)）。

::: warning 社内判定では
判定メモにも、周知技術を使うなら「**周知例として文献X、Y**」と根拠を書きましょう。あとで別の人が見ても判断の筋道がたどれるようにしておくのが、良い判定メモです。
:::
