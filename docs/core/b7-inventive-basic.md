# B7 進歩性① 基本の考え方

<p class="lead">新規性があっても、「その分野の人なら簡単に思いつく」ものには特許は与えられません。これが進歩性です。判定業務でいちばん頭を使うところなので、4回に分けてじっくり見ていきます。</p>

::: tip ざっくり言うと
- 進歩性の判断は、「**当業者**が先行技術から**容易に想到できた**」という**理屈（論理付け）が立つか**どうかで決まる
- 当業者は「その分野の技術常識を持ち、普通の創作能力があり、技術水準を全部知っている人」。ただし本願の発明のことは知らない
- 主引用発明を1つ選び、そこから出発して相違点を埋められるかを考える
:::

## 条文と趣旨

::: info 原文（特許法29条2項）
特許出願前にその発明の属する技術の分野における通常の知識を有する者が前項各号に掲げる発明に基いて容易に発明をすることができたときは、その発明については、同項の規定にかかわらず、特許を受けることができない。
:::

::: info 原文（基準 III-2-2 1.）
当業者が容易に発明をすることができたものについて特許権を付与することは、技術進歩に役立たず、かえってその妨げになるからである。
:::

## 判断の基本：論理付け

::: info 原文（基準 III-2-2 2.）
審査官は、請求項に係る発明の進歩性の判断を、先行技術に基づいて、当業者が請求項に係る発明を容易に想到できたことの論理の構築(論理付け)ができるか否かを検討することにより行う。<br>
当業者が請求項に係る発明を容易に想到できたか否かの判断には、進歩性が否定される方向に働く諸事実及び進歩性が肯定される方向に働く諸事実を総合的に評価することが必要である。そこで、審査官は、これらの諸事実を法的に評価することにより、論理付けを試みる。
:::

「なんとなく簡単そう」ではダメで、**誰が読んでも納得できる理屈**を組み立てられるかがポイントです。

## 「当業者」ってどんな人？

::: info 原文（基準 III-2-2 2.）
以下この部において「当業者」とは、以下の(i)から(iv)までの全ての条件を備えた者として、想定された者をいう。当業者は、個人よりも、複数の技術分野からの「専門家からなるチーム」として考えた方が適切な場合もある。<br>
(i) 請求項に係る発明の属する技術分野の出願時の技術常識(注1)を有していること。<br>
(ii) 研究開発(文献解析、実験、分析、製造等を含む。)のための通常の技術的手段を用いることができること。<br>
(iii) 材料の選択、設計変更等の通常の創作能力を発揮できること。<br>
(iv) 請求項に係る発明の属する技術分野の出願時の技術水準(注2)にあるもの全てを自らの知識とすることができ、発明が解決しようとする課題に関連した技術分野の技術を自らの知識とすることができること。
:::

イメージとしては、「**その分野の文献を全部読んでいて、普通の工夫はできるけれど、ひらめきの天才ではない人**」です。そして、本願の発明のことは知らない状態で考えます。

::: info 原文（基準 III-2-2 2.）
請求項に係る発明についての知識を有しないが、この技術水準にあるもの全てを自らの知識としている当業者であれば、本願の出願時にどのようにするかを常に考慮して、審査官は論理付けを試みる。
:::

## 技術常識・周知技術・慣用技術・技術水準

似た言葉が多いので、整理しておきましょう。

| 用語 | 意味 |
|---|---|
| **技術常識** | 当業者に一般的に知られている技術（周知技術・慣用技術を含む）、または経験則から明らかな事項。実験・分析・製造の方法、技術上の理論なども含む |
| **周知技術** | その技術分野で一般的に知られている技術（例：相当多数の文献がある、業界に知れ渡っている、例示する必要がないほどよく知られている） |
| **慣用技術** | 周知技術であって、**かつ、よく用いられている**技術 |
| **技術水準** | 先行技術のほか、技術常識その他の技術的知識から構成されるもの |

::: info 原文（基準 III-2-2 2.(注1)）
当業者に一般的に知られているものであるか否かは、その技術を記載した文献の数のみで判断されるのではなく、その技術に対する当業者の注目度も考慮して判断される。
:::

## 判断の手順 (1)〜(4)

::: info 原文（基準 III-2-2 3.）
審査官は、先行技術の中から、論理付けに最も適した一の引用発明を選んで主引用発明とし、以下の(1)から(4)までの手順により、主引用発明から出発して、当業者が請求項に係る発明に容易に到達する論理付けができるか否かを判断する。審査官は、独立した二以上の引用発明を組み合わせて主引用発明としてはならない。
:::

手順を図にすると、こうなります。

```
主引用発明を1つ選ぶ
   ↓
(1) 相違点について、否定する方向の要素（動機付け・設計変更等・寄せ集め）で
    論理付けできる？
   ├─ できない → (2) 進歩性あり
   └─ できる
        ↓
    (3) 肯定する方向の要素（有利な効果・阻害要因）も含めて総合評価
        ├─ 論理付けできない → (4) 進歩性あり
        └─ 論理付けできた   → (4) 進歩性なし
```

| 否定する方向に働く要素（→ [B8](/core/b8-inventive-negative)） | 肯定する方向に働く要素（→ [B9](/core/b9-inventive-positive)） |
|---|---|
| 主引用発明に副引用発明を適用する**動機付け**<br>（1）技術分野の関連性<br>（2）課題の共通性<br>（3）作用、機能の共通性<br>（4）引用発明の内容中の示唆 | **有利な効果** |
| 主引用発明からの**設計変更等** | **阻害要因**<br>例：副引用発明を主引用発明に適用すると、主引用発明がその目的に反するものとなる場合等 |
| 先行技術の**単なる寄せ集め** | |

::: info 原文（基準 III-2-2 3.）
審査官は、上記の(1)から(4)までの手順により論理付けができるか否かを判断する際には、当業者であれば本願の出願時にどのようにするかを常に考慮する。例えば、主引用発明からの設計変更等(3.1.2(1)参照)や、阻害要因(3.2.2参照)等の要素を考慮する際には、引用文献に明示的に記載された課題に過度にとらわれることなく、当業者にとって自明な課題や、引用発明に接した当業者であれば出願時の技術常識に基づき容易に着想し得る課題についても考慮する。<br>
また、上記(3)の手順に関し、進歩性が否定される方向に働く要素及び進歩性が肯定される方向に働く要素に係る諸事情に基づき総合的に評価する際には、3.1以降に示す各要素について、それぞれの要素の有無のみならず、それらの程度の差異も踏まえて評価する。
:::

「あるか・ないか」の二択ではなく、**どのくらい強いか**も含めて天秤にかける、というイメージです。

[判断フローを体験する](/practice/flow) で、この手順を実際にたどってみましょう。

::: warning 社内判定では
判定結果を研究員さんに伝えるときは、審査官の拒絶理由通知と同じく、

1. 主引用発明はどれか
2. 相違点は何か
3. その相違点を埋める副引用発明・周知技術・設計変更は何か、動機付けは何か
4. 肯定する方向の事情（効果・阻害要因）はあるか

の形でまとめると、説得力が出ます。「たぶん進歩性はないと思います」ではなく、**論理付けの形**で説明しましょう。
:::
