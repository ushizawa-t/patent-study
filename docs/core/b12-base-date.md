# B12 判断の基準時

<p class="lead">「出願より前」の「出願」はいつのこと？ 分割出願や優先権を主張した出願では、基準になる日がずれます。</p>

::: tip ざっくり言うと
- 原則は「特許出願の**時**」（時刻まで）
- 分割・変更出願 → **原出願**の出願時
- 国内優先権 → **先の出願**の出願時
- パリ優先権・国際特許出願 → 第一国出願の出願**日**・国際出願**日**（ここだけ「時」ではなく「日」）
:::

::: info 原文（基準 III-2-3 6.）
新規性及び進歩性判断の基準時(特許出願の時)は、下表のように取り扱われる。
:::

| 出願の種類 | 特許出願の時 |
|---|---|
| 分割出願、変更出願又は実用新案登録に基づく特許出願 | 原出願の出願時（第44条第2項、第46条第6項又は第46条の2第2項） |
| 国内優先権の主張を伴う出願 | 先の出願の出願時（第41条第2項） |
| パリ条約（又はパリ条約の例）による優先権の主張を伴う出願 | 第一国出願の出願日（パリ条約第4条B）（注） |
| 国際特許出願 | 国際出願日（第184条の3第1項）（注）。ただし、優先権の主張を伴う場合は、上欄のとおり |

（注）例外的に、「出願時」ではなく、「出願日」で新規性及び進歩性が判断される。

::: warning 社内判定では
国内優先権を使って**改良発明を追加**した場合、先の出願に書いてあった発明は先の出願の時が基準ですが、**あとから追加した部分**は後の出願の時が基準になります（優先権の効果が及ぶのは、先の出願の当初明細書等に記載された発明についてだけ）。その間に自社が学会発表などをしていると、追加部分の新規性に影響することがあります。→ [C10 優先権・分割](/related/c10-priority)
:::
